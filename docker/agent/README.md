# Изолированная контейнерная среда для dev-агентов

Безопасная замена запуску агентов под root на прод-сервере. Агент работает в **одноразовом Docker-контейнере**, изолированном от прода.

## Зачем
Запуск автономного агента (`bypassPermissions`) под root на прод-машине = радиус поражения = весь прод (БД, .env, соседние проекты). Контейнер это устраняет.

## Модель безопасности
- **Non-root** внутри (юзер `agent`) → claude bypass разрешён, и это слой изоляции.
- **Нет хост-монтирований прода.** Репо клонируется ВНУТРЬ контейнера из GitHub. С хоста монтируется только бриф (`brief.txt`, read-only).
- **Секреты только через `--env-file`**, не запекаются в образ:
  - `GH_TOKEN` — fine-grained PAT, права **только на репо** (Contents + PR write). Даже при утечке радиус = этот репозиторий.
  - `ANTHROPIC_API_KEY` — отдельный ключ (не личный OAuth), желательно с бюджет-лимитом.
- **`--rm`** — контейнер удаляется после задачи (disposable).
- **Лимиты** `--memory=2g --cpus=2`.

## Установка (один раз)
```bash
# 1. Собрать образ
docker build -t aidacamp-agent:latest docker/agent

# 2. Создать файл секретов (твоими руками — креды)
cp docker/agent/agent-secrets.env.example ~/.agent-secrets.env
chmod 600 ~/.agent-secrets.env
#   → вписать GH_TOKEN (fine-grained PAT на репо) и ANTHROPIC_API_KEY
```

## Запуск задачи
```bash
./scripts/agent-docker.sh "короткое имя" "детальный бриф задачи"
```
Контейнер: клонирует репо → ветка `agent/<slug>` от dev → claude над брифом → commit → push → PR в dev → самоудаляется.

## Что НЕ может агент (границы)
- Видеть/трогать прод-файлы, `/opt`, `/root`, прод-`.env`, соседние проекты — их нет в контейнере.
- Мержить в dev/main или деплоить прод — только PR; мерж и прод-деплой остаются за владельцем.
- Выйти за пределы прав `GH_TOKEN` (только этот репо).

## Дальнейшее ужесточение (опц.)
- Ограничить egress контейнера до api.anthropic.com + github.com (iptables/`--network` кастомный).
- Запускать на отдельной dev-машине, а не на прод-хосте (вариант B).
- Rootless Docker / gVisor для усиления изоляции ядра.
