# АйДаКемп — Project Rules

> **⚡ Правило №1 (разработка) — по риску, не по умолчанию** (03.08.2026). Docker-изоляция — только там, где цена ошибки высокая.
> - **Docker обязателен**, если правка трогает деньги/платежи, персональные данные (дети/родители/контакты), прод-доступ/секреты, или что-то, что не жалко сломать по-крупному: `./scripts/agent-docker.sh "<задача>" "<бриф>"` (одноразовый non-root контейнер). Детали — [`DEV_PROTOCOL.md`](DEV_PROTOCOL.md) → «Правило №1» + [`docker/agent/README.md`](docker/agent/README.md).
> - **Мелкие правки** (UI, вёрстка, безобидный SQL, косметика) — headless `claude -p` на сервере от non-root `claude-run` (`ssh aidacamp` → `sudo -u claude-run ...`); репо в его домашнюю папку, не трогать root-owned `/opt/aidacamp-site`.
> - Локально на маке — только хотфиксы владельца.
> - ⚠️ Старый `vps-start-agent.sh` (агент под root на проде) — **DEPRECATED**, не путать с `claude-run`.

## СТАРТ КАЖДОЙ СЕССИИ

**Два репозитория — не путать:** сайт → `~/Aidacamp-cloude` (ветка `dev`); MCP-сервер → `~/MCP` (ветка `main`).

Алгоритм: понять сайт или MCP → перейти в папку → `git branch` → `git fetch origin && git pull --rebase origin dev` → **агент:** `./scripts/agent-start.sh "<задача>"` (изолированный worktree).

## Используй только aidacamp-tools MCP

**НЕ используй:** Kapture, Desktop Commander, Chrome MCP, Claude in Chrome, удалённый MCP `5967f77d`. Всё — через `aidacamp-tools` (документация: [`TOOLS.md`](TOOLS.md)). Известные кампании Директ: `708664426` (Поиск), `708698819` (РСЯ).

## Факты vs гипотезы (жёсткое правило)

1. **Факт** — только подтверждённое данными/документацией (ссылка обязательна).
2. **Гипотеза** — явно помечать: «гипотеза» или 🤔.
3. **Не найдено** — честный ответ лучше, чем додумать.
4. API-вопросы: сначала документация, потом тест. Не гадать.

## ⚙️ Ресурсы: работать на сервере, не на маке

Мак владельца — MacBook Air M1, **8 ГБ RAM** (не апгрейдится); параллельные тяжёлые процессы забивают своп и тормозят все сессии (инцидент 11.07.2026). Приоритет размещения тяжёлого/фонового:
1. **Удалённый MCP-сервис** (по образцу `aidacamp-tools`) — если не нужен локальный контекст пользователя.
2. **systemd на проде** (`aidacamp-prod`, 159.194.223.55) **с cgroup-лимитами** (`MemoryMax=`/`CPUQuota=`) — сервер сам ограничен (5.8 ГБ RAM, диск 90%+); перед добавлением `free -h` и `df -h`.
3. **Локально на маке** — только когда нужен пользовательский контекст (Chrome с логинами) или разовая команда.

Доступ с мака к серверным демонам — SSH-туннель как **launchd-агент** в `~/Library/LaunchAgents/` (не `ssh -N -L` в фоне сессии — умирает с сессией). Карта мощностей — [`INFRA.md`](INFRA.md).

**⏳ Долгие операции — НИКОГДА одним блокирующим вызовом** (ни `sleep N`, ни цепочка блокирующих запросов): у клиента свой тайм-аут (~4 мин), результат теряется безвозвратно (инцидент 13.07.2026: 4 из 8 видео Replicate). Только фон на сервере (`nohup`/tmux/systemd) + лог + короткая проверка (`tail`). Паттерн — [`TOOLS.md`](TOOLS.md) → «Долгое ожидание / поллинг внешнего API».

## 🚫 Критичные инварианты (нарушение = инцидент)

- **Позиционирование бренда** — любой клиентский текст ДОЛЖЕН соответствовать. Главный принцип: продаём маме «я хорошая», не пользу для детей. Без нотаций, педтерминов, тона «эксперта в очках». Дарья — мама **дочери** (не сына!). Детали + 5 вопросов-фильтров → [`agent_docs/brand-positioning.md`](agent_docs/brand-positioning.md).
- **Цены/даты/смены — единый источник `src/data/shifts.ts`**, текущая цена только `getCurrentPrice()`. НИКОГДА не хардкодить цену/дату/трансфер в компонентах/боте/SEO. Стражи `check:prices`/`check:dates`/`check:transfer` роняют билд. Таблицы + правило роста + налоговый вычет → [`agent_docs/content-data-sources.md`](agent_docs/content-data-sources.md).
- **BANNED WORDS:** `единиц`/`баллы` → `рубл-`; массовое `дети`/`ребёнок` → `ребята`/`школьники`/`подростки`. Страж `check:banned` в билде. Детали → [`agent_docs/content-data-sources.md`](agent_docs/content-data-sources.md).
- **Новые гео/возрастные SEO-лендинги** — шаблонные через `src/data/landings/` + `[slug]`, со смысловым углом — обычный `.astro`. Существующие 180+ НЕ переносить (сознательная SEO-политика). Детали → [`agent_docs/content-data-sources.md`](agent_docs/content-data-sources.md).
- **Медиа — единое хранилище `/var/www/aidacamp-media/`** (nginx alias на prod и dev). НЕ копировать в client-каталоги, НЕ синкать между dev/prod. Детали → [`agent_docs/media-storage.md`](agent_docs/media-storage.md).
- **⛔ Запрещённые зависимости:**
  - `@astrojs/partytown` — НИКОГДА (ломает Метрика-цели → 0 конверсий; инцидент 16–18.04.2026: ~60К₽ потерь). Билд падает на `scripts/guard-no-partytown.sh`.
  - `permanently=true` в Яндекс.Диск API — только `permanently=false` (инцидент: 9000+ фото утеряны).
