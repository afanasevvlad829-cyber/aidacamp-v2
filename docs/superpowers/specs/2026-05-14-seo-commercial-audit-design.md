## Фазы аудита

### Фаза 0 — Данные (выполнена на 2026-05-14, повторить перед стартом)
- Позиции из `seo_position_snapshots` — последний снепшот 2026-05-06, перед стартом запустить свежую проверку через Topvisor
- Приоритетные страницы определены (см. таблицу выше)
- Конкуренты на ТОП-1–3 — брать из `competitor_urls` / `top10_domains` в свежем снепшоте

### Фаза 1 — Технический аудит
**Инструменты:** скилл `page-audit` + Lighthouse через browser-agent (сервер)  
**На каждую страницу проверяем:**
- Title (длина, ключ в начале, уникальность)
- Meta description (длина, CTA, ключ)
- H1 — один, совпадает с главным ключом
- Canonical (нет ли петель)
- Core Web Vitals: LCP, CLS, FID/INP (мобильный и десктоп)
- Structured data: `Organization`, `LocalBusiness`, `FAQPage`, `BreadcrumbList`
- Внутренняя перелинковка: сколько входящих ссылок у каждой посадочной

**Выход:** таблица проблем с приоритетом (критично / важно / желательно)

### Фаза 2 — E-E-A-T и семантика
**Инструменты:** скилл `eeat-audit` + `semantic-gap-analysis`  
**E-E-A-T:**
- Есть ли на странице сигналы экспертизы (факты, цифры, методика)
- Доверие: лицензии, отзывы, Яндекс.Карты, ФИО автора/основателя
- Актуальность: год 2026 явно упомянут, свежий контент
- Опыт: реальные фото, конкретные истории, не stock

**Семантический разрыв:**
- Берём ТОП-1–3 конкурентов по ключевому запросу
- Скрейпим их контент (browser-agent)
- Сравниваем с нашим: какие слова/темы/вопросы есть у них, нет у нас
- Приоритет: слова с высокой корреляцией с ТОП-3

**Выход:** список семантических пробелов + список E-E-A-T правок

### Фаза 3 — Оптимизация сниппетов
**Инструменты:** скилл `featured-snippet-optimizer`  
**Фокус:** страницы на позициях 4–9 — кандидаты на прыжок в ТОП-3 через snippet  
**Что смотрим:**
- Есть ли featured snippet по нашим ключам (колдунщики Яндекса)
- Формат контента для захвата: список, таблица, определение
- Правильная структура H2/H3 для snippet extraction

**Выход:** рекомендации по структуре для каждой страницы

### Фаза 4 — Реализация
**Инструменты:** `improve-content` / `edit-article`  
По итогам фаз 1–3:
- Конкретный список правок с приоритетами (Quick Win / Normal / Long-term)
- Quick Win (день): title/description/H1 правки, structured data
- Normal (неделя): добавление семантики, переписать разделы под snippet
- Long-term (месяц): E-E-A-T улучшения (новые отзывы, фото, лицензии)
