# ADR-003. src/pages/demo/ — живая песочница дизайна, не мусор

Дата: 2026-07-17 · Статус: принято
Источник: PR #1025 «chore(cleanup): удалить мёртвый прототип-рантайм и протухшие demo-страницы (−21,4k строк)» (MERGED); `astro.config.mjs` (строки ~44 и ~114 — demo исключены из sitemap); сессия ревью 17.07.2026.

## Контекст
В `src/pages/demo/` лежат экспериментальные страницы (design-system, hero-варианты,
blocks и т.п.). При чистках возникал соблазн удалить каталог как мусор.

## Решение
`src/pages/demo/` — сознательная живая песочница дизайна. Протухшие эксперименты
удалены отдельно (PR #1025), остальное — рабочий инструмент. Песочница исключена
из sitemap (фильтр `!page.includes('/demo/')` и `Exclude: [/demo\//]`
в `astro.config.mjs`) и из стражей.

## Следствия
- Не удалять `src/pages/demo/` при чистках «мёртвого кода».
- Новые дизайн-эксперименты — сюда, а не в боевые страницы.
- SEO-рисков нет: demo не попадает в sitemap.
