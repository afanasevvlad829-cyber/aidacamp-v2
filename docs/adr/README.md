# ADR — журнал архитектурных решений

Зачем: фиксировать **сознательные** решения, чтобы следующий агент/человек не «чинил»
то, что сделано намеренно (см. инциденты в CLAUDE.md).

## Формат записи

Файл `NNN-korotkoe-imya.md`:

```
# ADR-NNN. Заголовок решения
Дата: YYYY-MM-DD · Статус: принято
Источник: PR/файл/док, откуда решение подтверждено

## Контекст
## Решение
## Следствия
```

Правила:
- ADR не редактируются задним числом — устаревшее решение отменяется новым ADR
  со ссылкой на старый;
- каждое утверждение — со ссылкой на источник (PR, файл кода, док репо);
- новые ADR — по мере принятия решений, не пачками задним числом.
