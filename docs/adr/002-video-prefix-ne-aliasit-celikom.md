# ADR-002. Префикс /video/ нельзя алиасить целиком

Дата: 2026-07-17 · Статус: принято
Источник: сессия ревью 17.07.2026 (в связке с PR #1027); snippet `/etc/nginx/snippets/aidacamp-site-media.conf` (серверный конфиг); код: `src/pages/video/[slug].astro`, `src/pages/video/index.astro`.

## Контекст
При выносе медиа в единое хранилище (ADR-001) напрашивалось заалиасить в nginx весь
префикс `/video/` на `/var/www/aidacamp-media/`. Но под `/video/` живут НЕ только
файлы: в репо есть HTML-страницы `src/pages/video/[slug].astro` и
`src/pages/video/index.astro` — алиас целиком отдал бы вместо них файловую папку.

## Решение
Префикс `/video/` целиком не алиасится. В nginx-snippet алиасятся только 4 точечных
видеофайла (перечислены в самом snippet); остальные URL под `/video/` обслуживает сайт.

## Следствия
- Новые страницы `/video/<slug>` работают без правок nginx.
- Новый видеоФАЙЛ под URL `/video/...` требует точечного добавления в snippet —
  либо класть его в `/videos/` (алиасится целиком).
- «4 точечных файла» — факт с серверного snippet, из репо не проверяется
  (см. «Открытые вопросы» в ARCHITECTURE.md).
