# ADR-005. Разметка видео-лайтбоксов не сливается, общий только JS

Дата: 2026-07-17 · Статус: принято
Источник: комментарий в шапке `src/scripts/videoLightbox.ts` (цитата ниже); сессия ревью 17.07.2026.

## Контекст
`VideoGallery.astro` и `VideoCarouselVertical.astro` имеют почти одинаковые лайтбоксы —
напрашивалось слить их в один компонент.

## Решение
Разметка и CSS сознательно НЕ сливаются; общий — только JS-контроллер
`src/scripts/videoLightbox.ts`. Цитата из шапки файла:

> «Общий контроллер лайтбокса с Plyr + караоке-субтитрами (VTT) для
> VideoGallery.astro и VideoCarouselVertical.astro. Разметка и CSS у них
> разные (десктоп-грид+карусель с альбомными превью vs только карусель
> с портретными) — сливать рискованно для вёрстки двух живых страниц.
> Здесь только JS-поведение, которое у них буквально совпадало.»

## Следствия
- Не предлагать «отрефакторить дублирующиеся лайтбоксы» — это принято сознательно.
- Изменения поведения (play, караоке, аналитика) — в `videoLightbox.ts`, один раз.
- Изменения вёрстки — в каждом компоненте отдельно.
