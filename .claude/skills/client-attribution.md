# Client Attribution Skill

## 0. Время появления лида — якорь
- Карточка авто (бот/форма) → время = время заявки
- Карточка вручную → ищем контакт РАНЬШЕ в звонках/мессенджерах
- Рядом достижение цели в Метрике → матч +/-90 мин → источник
- «Заявка с сайта» = форма, НЕ источник. Докапывать визит.

## 1. Источники данных
- AlfaCRM: дата, телефон, lead_source_id, примечание (ymCid/tg_peer_id), группы
- Метрика Logs API: визиты, источник, цели, ClientID, реферер, фраза (счётчик 96499295)
- Telegram-бот: заявки с реальным реферером
- Звонки: ZAdarma CSV + мобильный Дарьи xlsx
- tg_peer_id в примечании CRM

## 2. Приёмы (все к каждому клиенту)
1. Несколько групп/школьная = старый клиент [100%]
2. ymCid из примечания → Метрика Logs API → источник первого визита [100%]
3. Телефон → бот: реферер (codims/yandex-cpc/ysclid/SEO-страница) [100%]
4. tg_peer_id → мессенджер [100%]
5. Телефон → звонки: входящий >=20сек до карточки → звонок [100%]
6. Раннее «на сайте с» → знал задолго (контекст)
7. МАТЧ ПО ВРЕМЕНИ: цель Метрики +/-90мин от карточки → источник [100%]
8. Семья по телефону → склейка
9. lead_source_id AlfaCRM → расшифровка, НЕ доказательство (ВРЁТ)
10. Прямой URL на смену → предположение рекомендация

## 3. Алгоритм
1. Карточка → дата, телефон, группы, примечание
2. Группы школьные? → БАЗА [100%]. Стоп
3. tg_peer_id? → запомнить
4. ymCid? → Метрика → источник [100%]
5. Телефон → бот с реферером? → источник [100%]
6. Телефон → входящий звонок? → ЗВОНОК [100%]
7. Нет ymCid? → матч по времени → источник [100%]
8. Только tg_peer_id? → Telegram [100%]
9. Ничего? → карточка авто = «заявка, источник не виден» / ручная = «НЕ НАЙДЕНО»
10. Семья: склеить

## 4. Метрика
Цели: 541048197 form_submit, 545216440 телефон, 556953493 TG, 556953501 WA, 571468312 Новофон
Поля: clientID, dateTime, lastTrafficSource (ad/organic/direct/referral/messenger),
lastAdvEngine (ya_direct=Директ), UTMSource/Medium, lastSearchPhrase, goalsID
Процесс: POST logrequests → опрос → download TSV. date2 < сегодня.

## 5. AlfaCRM API
host codim.s20.online, auth POST /v2api/auth/login, заголовок X-ALFACRM-TOKEN
POST /v2api/5/customer/index {id:N}. ymCid в ТЕКСТЕ примечания (custom_ym_uid пустой!)
lead_source_id branch=5: 9=Сайт, 20=Директ, 11=Друзья, 15=Районные, 10=Телеграм, 8=ВК

## 6. Достоверность (ОБЯЗАТЕЛЬНА)
100% — прямое доказательство
предположение — косвенно
гипотеза — основание есть, привязка не доказана
нет данных — только CRM-метка
Правило: CRM «Директ» без доказательств = «нет данных», не «Директ».

## 7. Ловушки
1. CRM-метка врёт массово
2. /p/{id} = памятка, не привлечение
3. aidacamp.ru/ в боте = внутренний реферер
4. direct в Метрике != Яндекс Директ (Директ = ad/ya_direct)
5. Поздний звонок в заезд = орг-вопрос
6. «Заявка с сайта» = форма, не источник
7. ym_uid в ТЕКСТЕ примечания, не в custom-поле

## 8. Эталон
106 клиентов (смены 1+3-6): Директ = 2 (~2%) при 410К расхода.
Все CRM-метки «Директ» ложные.
База+звонки+органика = 54%, ноль бюджета.
Если разбор даёт больше Директа — перепроверить: поверили CRM-метке.
