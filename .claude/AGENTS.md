## Зоны ответственности (не пересекаются)

Когда создаёшь нового агента — назначь ему зону из списка ниже или определи новую.

| Зона | Папки/файлы |
|---|---|
| UI-компоненты | `src/components/**` |
| Страницы | `src/pages/**` |
| Стили | `src/styles/**` |
| Контент | `src/content/**` |
| Скрипты/конфиги | `scripts/**`, `*.config.*` |
| SEO-лендинги | `src/pages/landing/**` |
| Изображения | `public/images/**` |
| Инструменты (ветка `tooling`) | `tools/**` — только в orphan-ветке `tooling`, не в `dev`/`main` |
| CI workflows | `.github/workflows/**` |
