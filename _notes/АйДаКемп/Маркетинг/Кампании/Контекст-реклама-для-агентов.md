### Критические уроки Директ (не повторять!)

1. **Не копировать замёрзшую стратегию** — дубль при копировании ставит AVERAGE_CPA 100₽ → замерзает сразу
2. **Target CPA = реальная × 1.5-2** — реальная стоимость «Выбор возраста» ~248₽ → ставим 400-500₽
3. **Пакетные кампании (Error 5005)** — стратегию пакетных кампаний менять ТОЛЬКО через UI Директа, не через API
4. **AVERAGE_CPA ≠ WB_MAXIMUM_CLICKS** — первая оптимизирует под цель, вторая только кликает
5. **WeeklySpendLimit=null** — без ограничения бюджета, алгоритм работает лучше
6. **Минимум 10 конверсий/нед** — иначе алгоритм замерзает. У нас только «Выбор возраста» проходит этот порог
