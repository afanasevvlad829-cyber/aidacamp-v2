> Применять если: CPA был поднят (700₽ Search / 500₽ РСЯ), WSL снят, прошло **≥1 часа**, а показов и кликов по-прежнему 0.

> Причина: алгоритм PAY_FOR_CONVERSION заморозил обучение после 2 дней нулей (16-17.04 Partytown-инцидент), повышение CPA не сдвинуло его с мёртвой точки.

Создаём 3 **новые** кампании (копии текущих 708615379 / 708664426 / 708698819) в **НОВЫЙ пакет стратегии** (не 707632923 — у него тоже испорчена история).

## Пошагово — 15 минут в UI direct.yandex.ru

### 0. Подготовка — ставим текущие на паузу

Чтобы не плодили дубли в одном аукционе:

1. **direct.yandex.ru** → кабинет AidaCamp
2. Кампания 708664426 **AidaCamp | Search | V2 pilot** → ⏸ **Остановить**
3. Кампания 708615379 **Ретаргет по аудиториям** → ⏸ **Остановить**
4. Кампания 708698819 **РСЯ лагерь / Claude / 03-04-2026** → ⏸ **Остановить**

### 1. Копируем Search (708664426)

1. Галочка напротив кампании → **Действия → Копировать**
2. В появившейся форме:
   - **Название:** `AidaCamp | Search | V3 restart 2026-04-19` (дата для истории)
   - **Стратегия:** PAY_FOR_CONVERSION
   - **Цель:** `age_select` (541048270) — **проверить что выбрана**
   - **CPA:** 500₽ (не 400 — даём алгоритму больше воздуха на старте, через 7 дней снизим)
   - **Недельный бюджет:** не ставим (пусто) или 50 000₽
   - **Оплата:** за конверсии
   - **Пакетная стратегия:** **НЕ включать в 707632923!** Либо выбрать "Отдельная", либо создать новый пакет `V3 pilot`
3. **Сохранить** → кампания появится в статусе «Модерация» (обычно 10-30 мин)
4. Проверить объявления/ключи/минус-площадки — должны скопироваться. Если нет — скопировать вручную

### 2. Копируем РСЯ (708698819)

1. Выделяем → Копировать
2. Параметры:
   - **Название:** `РСЯ лагерь / V3 restart 2026-04-19`
   - **Стратегия:** PAY_FOR_CONVERSION, CPA **500₽** (на РСЯ держим то же что было)
   - **Цель:** age_select
   - **Пакет:** новый `V3 pilot` (тот же что у Search выше — **общий новый пакет**)
3. Сохранить

### 3. Копируем Ретаргет (708615379)

1. Выделяем → Копировать
2. Параметры:
   - **Название:** `Ретаргет API / V3 restart 2026-04-19`
   - **Стратегия:** PAY_FOR_CONVERSION, CPA **400₽** (ретаргет должен быть дешевле — аудитория тёплая)
   - **Пакет:** тот же новый `V3 pilot`
   - **Аудитории/ретаргетинг-списки** — проверить что скопировались из CRM-аудиторий (54735835/54735836)
3. Сохранить

### 4. Проверка перед запуском

- ✅ Все 3 новые в новом пакете `V3 pilot`
- ✅ Старые 708615379/708664426/708698819 в статусе **Остановлена** (не удаляем — их можно потом вернуть если обучение не взлетит)
- ✅ Балансы кампаний ненулевые
- ✅ В новых кампаниях нет blocked/заблокированных ключей
- ✅ Модерация прошла (не «Ожидает модерации»)

### 5. После запуска — мониторинг

```bash
# Проверять каждые 2-3 часа первые сутки
bash /Users/vladimirafanasev/MCP/stats.sh direct-status
```

Ожидаемая кривая обучения:

| Время | Ожидается |
|---|---|
| +2 часа | Первые показы (модерация + начало теста) |
| +24 часа | 100-300 показов, 1-3 клика, 0-1 конверсия |
| +48 часов | 1000+ показов, 5-15 кликов, 1-3 конверсии |
| +7 дней | Стабильный расход, 10+ конверсий → алгоритм обучен |

**Если через 24 часа 0 показов** — значит проблема не в стратегии, а в Метрике/аккаунте → остановить и написать в техподдержку Яндекса (кабинет → Поддержка, указать что создавали новые кампании в новом пакете, а они не крутятся).

## SQL для отслеживания из БД

```bash
# Все кампании последние 24 ч
bash /Users/vladimirafanasev/MCP/stats.sh query "
SELECT campaign_id, campaign_name, SUM(clicks) AS clks, SUM(impressions) AS imps, ROUND(SUM(cost)::numeric, 0) AS cost, SUM(conversions) AS conv
FROM direct_campaign_stats
WHERE date = CURRENT_DATE
GROUP BY 1, 2 ORDER BY cost DESC;
"
```
