## 📚 Best Practices (проверено в инете 20.04.2026)

### 🔴 Главное правило Яндекс.Директ 2025-2026
> Для стратегий с оплатой за конверсии (PAY_FOR_CONVERSION, AVERAGE_CPA) нужно **минимум 10 конверсий за 7 дней на кампанию**.
> Если меньше — **алгоритм замораживается**, показы падают до 0.

### 🟢 Правильный путь разгона новой кампании

| Фаза | Срок | Стратегия | Условие перехода |
|---|---|---|---|
| 1. Прогрев | 1-2 недели | **Оптимизация кликов** (OPTIMIZE_CLICKS_PAY_FOR_CLICKS) с потолком CPC | собрано 10-15 кликов + 3-5 конверсий |
| 2. Обучение | 2-3 недели | **Максимум конверсий** (OPTIMIZE_CONVERSIONS) с целью в «зелёной зоне» | кампания даёт ≥10 конв/нед стабильно |
| 3. Оптимизация | постоянно | **Оплата за конверсии** (PAY_FOR_CONVERSION) или AVERAGE_CPA | стабильно |

**Цели для автостратегий ранжируются по цвету в UI Директа:**
- 🟢 **Зелёная** — более 10 достижений/нед → стратегия обучается стабильно
- ⚪ **Серая** — мало данных → нестабильная работа

### 💡 Если CPA задан слишком низко
> Если система понимает что конверсии по такой цели невозможно получить дешевле, показы не запускаются. 

**Решения:**
1. Поднять цену конверсии до реалистичной
2. Переключиться на ОПЛАТУ ЗА КЛИКИ для накопления статистики
3. Использовать промежуточную цель выше в воронке

### 💰 Бюджет разгона
Минимум **10 000 ₽/неделю** по рекомендациям директологов.

## 🎯 План на 2026-04-20 (корректный, основан на best practices)

### ⚠️ Критическое уточнение стратегий

В Яндекс.Директ есть **две стратегии с оптимизацией по цели**:
1. **«Оптимизация конверсий»** (AVERAGE_CPA в API) — **оплата за клики**, алгоритм оптимизирует под цель. Работает при достаточно частой цели (🟢 «Выбор возраста» = 175/нед — ок)
2. **«Оплата за конверсии»** (PAY_FOR_CONVERSION в API) — платим только за достижение цели. Нужно ≥10 конв/нед для обучения.

**Наш выбор:** AVERAGE_CPA («Оптимизация конверсий с оплатой за клики»). Платим за клики, алгоритм стремится к конверсиям. Плюс **БЕЗ ограничения недельного бюджета** (Yandex сам распределяет по аукционам).

### Для 709159717 (Search)
- ✅ **AVERAGE_CPA**, Cpa 500₽, без WeeklySpendLimit
- GoalId 541048270 «Выбор возраста»
- Реальная среднеожидаемая стоимость конверсии ~250₽ → target 500₽ даёт алгоритму запас 2× для обучения

### 🔁 Пакетная стратегия (Shared Bidding Strategy)

**709159740 (РСЯ) + 709159767 (Ретаргет) используют общую пакетную стратегию**.

Что это означает:
- Обе кампании обучаются на **объединённом пуле конверсий** (РСЯ + Retarget)
- Настройки ставок и CPA — **общие** для обеих
- Это правильный подход когда по отдельности мало данных: **больше конверсий → быстрее обучение алгоритма**
- Нельзя менять стратегию каждой кампании по-отдельности через API → **ошибка 5005 "Field set incorrectly"**

### Правка пакетной стратегии (только в UI Директа)
- **Одна стратегия на обе кампании**: AVERAGE_CPA «Оптимизация конверсий с оплатой за клики»
- **Cpa 400₽** (единое значение для обеих)
- **БЕЗ WeeklySpendLimit** (без ограничения бюджета)
- **GoalId 541048270** «Выбор возраста»

**Почему 400₽ для пакетной:**
- Средняя реальная стоимость «Выбор возраста» = 248₽ (расчёт: 43 474₽/175 конв)
- Target 400₽ даёт алгоритму запас ~1.6× — не замерзнет, но и не будет транжирить
- Общий пул конверсий РСЯ+Retarget даёт быстрее обучение (10-15 конв/нед в сумме достижимо)

### Для 709159717 Search — отдельная индивидуальная стратегия
- Cpa 500₽ (дороже т.к. поиск = более дорогой клик но более быстрая конверсия)
- Этим кампанией можно управлять через API напрямую (не в пакете)

### Для 709159740 (РСЯ дубль — уже user ставил OPTIMIZE_CLICKS)

Аналогично — OPTIMIZE_CLICKS до накопления истории, потом PAY_FOR_CONVERSION.

### Для 709159767 (ретаргет)

Нужно отдельно проверить — ретаргет по тёплой аудитории может работать на PAY_FOR_CONVERSION сразу.

## 🧠 Уроки (чтобы не повторять)

1. **Не копировать стратегию "как было"** — если старая кампания замёрзла, значит её стратегия не работает. Переосмыслить.
2. **Проверять цель**: её должно быть ≥10 достижений/нед в рамках одной кампании (не на всём сайте!). **Но: при пакетной стратегии** пул объединяется — тогда можно и с меньшими объёмами по каждой кампании.
3. **Дублирование кампании в Директе** → Director **автоматом ставит AVERAGE_CPA 100₽** — проверять и менять вручную сразу
4. **"Оптимизация конверсий с оплатой за клики" (AVERAGE_CPA)** — это не то же самое что «Максимум кликов» (WB_MAXIMUM_CLICKS). Первая смотрит на цель, вторая — только на клики. Для разгона лучше AVERAGE_CPA с запасом target-CPA.
5. **Промежуточные цели для разгона** — «Выбор возраста» (175/нед) вместо «Отправка заявки» (4/нед)
6. **Пакетные стратегии (joint/shared)** — если кампании связаны, менять стратегию можно ТОЛЬКО через UI. API возвращает Error 5005 «Field set incorrectly». Признак: в UI кампании написано «Пакетная стратегия».
7. **Без ограничения бюджета** (WeeklySpendLimit=null) — для автостратегий с оплатой за клики это даёт алгоритму больше свободы в аукционах. Деньги всё равно списываются аккуратно — за клики в рамках CPA-target.
8. **Target CPA = реальная × 1.5-2** — иначе алгоритм замерзает. Реальная для нас ~248₽, ставим 400-500₽.
