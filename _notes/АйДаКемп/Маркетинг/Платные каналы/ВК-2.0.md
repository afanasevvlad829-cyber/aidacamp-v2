## Часть I. База знаний об алгоритмах VK Ads (2025-2026)

### 1. Архитектура показа — факт

**VK Ads = мультиплейсмент.** Один креатив показывается на:
- VK (лента, клипы, истории, сообщества)
- Одноклассники (лента, клипы)
- Mail.ru (почта, портал)
- Яндекс.Дзен (Pulse), партнёрская сеть Mail

Алгоритм **сам распределяет бюджет** по плейсментам. В отчётах плейсмент виден, но управлять им можно только через флаг `pads: [...]` при создании группы.

**Для АйДаКемп (факт по данным 16.04):** referer=m.ok.ru — 152 визита, значит реклама льёт в том числе в OK. Mail.ru/Pulse — визиты есть, но через пиксель, не через UTM (теряется referer при внутренних редиректах).

### 2. Стратегии оптимизации — факт

| Стратегия | Суть | Мин. для обучения |
|---|---|---|
| Максимум показов (CPM) | Охват | — |
| Максимум кликов (CPC) | Трафик | — |
| **Максимум конверсий** | Оптимизация на событие пикселя | ≥30 событий за 7 дней (гипотеза — VK не публикует точное число) |
| **Оплата за конверсию (CPA = priced_goal)** | Плата только за целевое действие | ≥30 событий в неделю на событие (гипотеза, из блогов 2026) |

**priced_goal — факт:**
- указывается ID события пикселя (у нас `micro_age_select=7761900`, `messenger=7717530` и др.)
- бюджет списывается только при достижении события в течение окна атрибуции
- цена цели устанавливается при создании, не менее минимальной по VK (зависит от вертикали)

### 3. Окна атрибуции — факт

- **Post-click: 7 дней** после клика по объявлению
- **Post-view: 7 дней** после показа без клика (отчёт VK отдельно)
- Всё внутри пикселя идентифицируется по **`rb_clickid`** — параметр, который VK автоматически добавляет в URL клика
- Last click attribution: новый rb_clickid перезаписывает старый в CRM

**Для АйДаКемп:** это значит — покупка лагеря в июне может быть атрибуцирована клику в апреле только если пиксель сопоставил rb_clickid в течение 7 дней. **LTV-атрибуция длиннее 7 дней — невозможна** средствами VK.

### 5. Обучение алгоритма — гипотеза и факты

**Факт — поле API `learning_progress`:**
- 0.0 — не обучен / мало данных
- 1.0 — **обучен** (эмпирически подтверждено 17.04: группа с lp=1.0 показала топ-результат 9036 показов / 193 клика)
- **Важно:** это НЕ «на обучении» (раньше интерпретировали ошибочно)

**Гипотеза (из блогов 2026):**
- Обучение стратегии «Максимум конверсий» требует **≥30 событий выбранной цели за 7 дней**
- Полный цикл обучения 7-14 дней
- После смены цели / резкой смены бюджета — переобучение 5-7 дней
- При <10 событий/нед за 14 дней — стратегия «голодает», показы падают

### 6. Таргетинг — факт

5 основных способов (суммируются внутри группы = пересечение, не объединение):
1. **Интересы и привычки** (категории VK)
2. **Ключевые фразы** (по поисковым/контентным сигналам в VK)
3. **Сообщества** (подписчики + активные)
4. **Ретаргетинг** — загруженные CSV, пиксель, look-alike
5. **Гео + пол + возраст** (всегда)

**Правило — факт (ze.media):** не совмещать в одной группе интересы + ключи + очень узкое гео → алгоритм не найдёт достаточно аудитории, показы встанут.

**Наши тиры (факт из ВК.md):**
- Tier 1: 503 чел, 150-200₽/день
- Tier 2: 3155 чел, 400-500₽/день
- Tier 3: 2846 чел, 350-450₽/день
- Tier 4: 2442 чел, 400-500₽/день

### 7. Look-alike — факт

- Минимум исходной аудитории **1 000 пользователей** для построения LAL (VK Ads требование)
- Источник: CSV email/phone/vk_id, сегмент пикселя, аудитория из посетителей сайта
- Точность 1-10% (чем меньше, тем ближе к исходному сегменту)

### 8. Форматы объявлений — факт

- **Универсальное** (мультиформат, `package_id=3232`) — сам подстраивается под плейсмент
- Клипы (вертикальное видео 9:16)
- Универсальная запись (нативная)
- Лид-формы (внутри VK)
- Карусель
- Баннер (РСЯ-like)

**Правило креативов (факт из vc.ru 2026):**
- Минимум **6-12 вариаций** на группу (алгоритм сам выбирает победителя)
- Первые **1-2 секунды — крючок** для видео
- Соотношения 1:1, 4:5, 16:9, 9:16 — делать сразу сетом

### 9. UTM и rb_clickid — факт (наше расследование 17-18.04)

**Как VK проставляет метки:**
- `enable_utm=true` на уровне группы + поле `utm` с шаблоном → VK добавляет к banner URL при клике
- Поддерживаются макросы: `{{banner_id}}`, `{{campaign_id}}`, `{{impression_hour}}`, `{{impression_weekday}}` (двойные фигурные!)
- `rb_clickid` добавляется всегда независимо от `enable_utm`
- Если `utm` пустой — VK добавляет автоматические метки (`utm_source=vkads` или подобное, нестандартно)

**Наши UTM-шаблоны (актуально 18.04):**
```
Группа «телефон»:       utm_source=vk_ads&utm_medium=cpa&utm_campaign=problem_photo
                         &utm_content=telefon_{{banner_id}}
                         &utm_term={{impression_hour}}_{{impression_weekday}}
Группы «nichego/leto»:   статичные (без макросов)
```

### 10. Потеря атрибуции — факт (наше расследование)

**Каскад потерь на пути клик→Метрика:**

1. VK Ads клик → редирект через vk.com/redirect (добавляет rb_clickid, UTM)
2. In-app WebView VK (у 60-80% мобильных юзеров) — **часто ломает** передачу referer, sometimes UTM
3. Переход на https://aidacamp.ru/?utm_*=...&rb_clickid=...
4. Страница загружается
5. **Yandex.Метрика должна успеть инициализироваться** до закрытия / ухода (факт: **проблема Partytown — исправлена PR #3 18.04**)
6. UTM и rb_clickid сохраняются в визит

**Что мы видим (факт 17-18.04):**
- VK: 193 клика по группе «телефон»
- Метрика: 0 визитов с `utm_source=vk_ads` от этой группы
- Предположительная потеря до PR #3: **70-90%** (гипотеза, проверить после деплоя)

### 🔴 КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ (факт 17-18.04)

**Сеть VK / mytarget_partners / «Автоматическое размещение» — ЗАПРЕЩЕНО включать.**

Что случилось 17.04:
- Поставили автоматическое размещение в одной кампании (чтобы «был трафик»)
- VK ушёл в Сеть VK (партнёрские сайты / DSP)
- VK API показал: **2 752 клика, CPC 4.72₽, расход 12 996₽** за сутки
- Метрика увидела только **10 визитов с utm_source=vk_ads** → атрибуция **0.4%**
- **Деньги ушли на фантомные клики**, реального трафика ≈ нет

**Правило:** если CPC в VK <10₽ при обычной норме 15-30₽ — алгоритм ушёл в Сеть VK. Эквивалент DSP-уровня мусора, как в Директе dsp-*.yandex.ru.

**Как избежать:** при создании группы в UI **выключать «Автоматическое размещение»**, оставлять только конкретные плейсменты (VK / OK / Проекты). Через API — управление плейсментами заблокировано permission `view_pads` (не выдан).

Эталон нормы (16.04): CPC 17₽, 207 кликов → 162 визита (78% атрибуция), трафик через OK bounce 18%.

### 📍 Блок P. PLACEMENTS

**Важно (факт, проверено 18.04):** **VK Ads API v2 НЕ даёт разбивку по плейсментам.** Endpoints `/statistics/pads/*`, `/statistics/placements/*`, параметр `grouping=pads` — все возвращают HTTP 404. Плейсменты видны только:
1. Через **веб-кабинет** VK Ads (раздел отчётов) — вручную
2. Через **Метрику** по `ym:s:refererDomain` — автоматически, но часть визитов теряет referer в in-app WebView

Возможные плейсменты (названия при создании группы через `pads: [...]`):
- `vk_feed` — лента VK
- `vk_clip` — клипы VK
- `vk_story` — истории VK
- `ok_feed` — лента Одноклассников
- `ok_clip` — клипы ОК
- `mail_feed` — лента Mail
- `pulse_feed` — Дзен/Pulse
- `mytarget_partners` — сеть партнёров (DSP-like)

**Правило (гипотеза):** `mytarget_partners` — аналог DSP в Яндексе. Если CPL там >2× среднего по группе → отключать через `pads`.

### 👥 Блок T. TARGETING × DEMO — источник данных

**Важно (факт):** VK Ads API v2 НЕ даёт разрезы по полу/возрасту/устройствам/гео. Endpoints `/statistics/socdem/*`, `/statistics/devices/*`, `/statistics/geo/*` возвращают 404.

Эти разрезы берём ТОЛЬКО из:
- **Яндекс.Метрика** — `ym:s:ageInterval`, `ym:s:gender`, `ym:s:deviceCategory`, `ym:s:regionCity` с фильтром `utm_source=vk_ads`
- **Веб-кабинет VK Ads** — вручную из интерфейса (не автоматизируется)

### 💰 Блок E. ECONOMICS

| Юнит | Формула | Норма АйДаКемп |
|---|---|---|
| Cost per messenger | spend / messenger_events | <500₽ |
| Cost per micro_age | spend / age_selects | <100₽ |
| Cost per lead | spend / form_submits | <2000₽ |
| CAC (если лид→продажа 30%) | CPL / 0.3 | <6500₽ |

**Экономика АйДаКемп (факт из РАДАР + клиент, 18.04.2026):**
- Средний чек: **75 000₽**
- Маржа с продажи: **~22 500₽** (≈30% чека)
- LTV **не учитываем** — горизонт планирования 1 сезон. Рынок, цены, площадки, алгоритмы меняются быстрее, чем ребёнок возвращается. Каждая продажа окупается в сезон или не окупается.

**Нормы CAC для АйДаКемп (жёсткие, факт клиента):**

| Уровень | CAC | Комментарий |
|---|---|---|
| 🏆 отлично | ≤5 000₽ | идеальная точка |
| 🟢 цель | 5 000–6 000₽ | здоровая эконом. |
| 🔴 потолок | **10 000₽** | **жёсткий предел — выше останавливаем канал или пересобираем** |

При CPL 2 000₽ и конверсии лид→оплата 30% → CAC = 6 667₽ → 🟢 на грани, желательно CPL ≤1 500₽ или CR ≥35%.

## Часть IV. Инсайты АйДаКемп (накоплены 16-18.04.2026)

### Атрибуция (критично)

1. **Partytown ломал Метрику** — исправлено PR #3 (18.04). До этого теряли ~70-90% UTM-атрибуции.
2. **Top.Mail.Ru (пиксель VK)** работал через deferred-loader — исправлено PR #2 (17.04). Потеря событий до 50% (гипотеза).
3. **VK in-app WebView** — всё ещё может терять referer, но UTM должны сохраняться если пиксель и Метрика грузятся синхронно.
4. **rb_clickid** — единственный надёжный идентификатор в экосистеме VK. Сохранять в куке, передавать в оффлайн-конверсиях.

### Стратегия (корректировки)

5. **priced_goal на messenger даст больше атрибуции, чем на lead** — мессенджер чаще достигается в рамках 7-дневного окна (факт ВК.md: messenger 8/нед vs lead 6/нед).
6. **Цель должна давать ≥30 событий/нед** — если меньше, переключать на микро.
7. **Обновление UTM-шаблона = НЕ переобучение стратегии** — но до 1-4 часов все активные креативы идут со старым шаблоном (гипотеза из наблюдений 17.04).

### Креативы (из РАДАР-инсайтов)

8. **Провокационные заголовки работают** — «Подойдёт не каждому ребёнку», «Он без телефона. Вы — без тревоги». DSP в Директе не появляется (а в VK — фокус держит на квалифицированной аудитории).
9. **Абстракции проваливаются** — «Среда развития», «Пока дети взрослеют» → алгоритм уходит в мусорные плейсменты.
10. **Двойной адресат (ребёнок+родитель)** — лучший формат для лагеря (семейный оффер).

### Аудитории

11. **LAL от «купивших ≥1 смену»** — приоритет над LAL от лидов (факт vc.ru 2026: строить от оплативших).
12. **Ретаргет по посетителям age-секции** — тёплая аудитория, обычно CPL -40% от холодного.
13. **Tier 1 (самая узкая)** — не подходит для обучения новой стратегии, охвата мало.

### Плейсменты

14. **OK.ru льёт значимый трафик** (152 визита 16.04) — проверить качество отдельно.
15. **Клипы/Stories vs лента** — для лагеря вертикальное видео с «историей одного ребёнка» работает лучше (гипотеза, проверить A/B).
