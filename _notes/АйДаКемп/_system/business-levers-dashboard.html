Трафик — верх воронки

Минус-площадки РСЯ

⭐⭐⭐

Эффект: −30% cost

Источник: Yandex Direct API (уже в ETL). Триггер daily в CM v3.

Эффект: +15% CR

metrika_demographics metrika_geo
Источник: Яндекс.Метрика API (уже в ETL).
