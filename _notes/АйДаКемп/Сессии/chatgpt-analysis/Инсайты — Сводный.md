# SYSTEM (152 диалогов)

### 1. Используемые системы и технологии
- **3CX**: система VoIP, использованная в различных задачах, включая настройки, транскрипцию и интеграцию.
- **Telegram API**: интеграция с CRM и создание ботов.
- **Wi-Fi оборудование**: Ruckus, UniFi, оценка и проектирование Wi-Fi покрытия.
- **HTML/CSS**: перевод дизайна в HTML и работа со стилями.
- **AI технологии**: инструменты для диктовки, генерации видео и озвучки.
- **Bitrix**: CRM-система, использованная для анализа клиентов и обработки звонков.
- **Tilda**: создание и настройка сайтов, работа с кодом.
- **GitHub**: управление версиями и интеграция с проектами.
- **Excel**: анализ данных и работа с таблицами.

### 2. ТОП-5 задач
1. **Настройка и интеграция 3CX**: проблемы с админкой, транскрипция, настройки e-mail, лицензирование.
2. **Работа с Telegram API**: создание ботов, интеграция с CRM, автоматизация отправки сообщений.
3. **Проектирование и оценка Wi-Fi**: анализ покрытия, радиопланирование, ошибки в настройках.
4. **Перевод и адаптация дизайна**: перевод дизайна в HTML, работа со стилями, создание скриптов для Tilda.
5. **Обработка и анализ данных**: парсинг клиентов, анализ изменений в документах, работа с датасетами.

### 3. Разовое vs системное
- **Разовое**: 
  - Быстрый ремонт платы.
  - Ошибки в отчетах 3CX.
  - Ошибка 404 на workspace.
  - Удаление виртуального микрофона.
  
- **Системное**: 
  - Настройки и интеграция 3CX.
  - Проектирование Wi-Fi покрытия.
  - Работа с Telegram API и CRM.
  - Перевод дизайна и адаптация.

### 4. Повторяющиеся проблемы (признак технического долга)
- **Проблемы с 3CX**: частые ошибки, настройки и лицензирование.
- **Ошибки с интеграцией API**: проблемы с GET-параметрами и загрузкой данных.
- **Проблемы с Wi-Fi**: постоянные ошибки в настройках и оценке покрытия.
- **Проблемы с обработкой данных**: дублирование звонков, ошибки в транскрипции.

### 5. Что можно было решить один раз и не возвращаться
- **Стандартизация настроек 3CX**: создание четкой документации по настройкам и лицензированию.
- **Автоматизация интеграций**: разработка универсальных скриптов для работы с Telegram API и CRM.
- **Создание шаблонов для HTML/CSS**: стандартизация процесса перевода дизайна.
- **Оптимизация Wi-Fi проектирования**: создание единой методологии для оценки и проектирования покрытия.
