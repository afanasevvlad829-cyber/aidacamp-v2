### ❌ ЧТО НЕ РАБОТАЕТ (5 каналов):
1. **Telegram** — ноль результата
2. **Email B2B** — ноль результата
3. **Reddit** — невозможен из России
4. **Avito** — очень мало заявок (маргинальный)

- Нельзя просить заявку/контакты сразу
- Сначала валидируем (выбор возраста, выбор смены)
- Потом уже ведём дальше

## 📋 Как использовать эти материалы

### Для руководителя:
1. Открой "**Результаты тестов — заполненная матрица**"
2. Читай итоговую сводку (таблица в конце)
3. Ознакомься с "**Стратегическим анализом**"
4. Выбери 2 приоритетных теста на Q2

### Для маркетолога:
1. Скопируй "**Шаблон для A-B теста**"
2. Заполни гипотезу и дизайн
3. Заполняй метрики **еженедельно** (не после!)
4. По итогам обновляй матрицу результатов

### Для аналитика:
1. Настрой Google Analytics 4
2. Используй UTM таблицу подмен (уже есть)
3. Еженедельно проверяй метрики из шаблона
4. Флаги проблемы сразу же

### Для других агентов/команды:
1. Это твой источник правды о статусе тестов
2. Открой "**Результаты тестов — заполненная матрица**" для информации
3. Используй "**Шаблон для A-B теста**" если запускаешь новый тест
4. Ссылайся на эти документы в отчётах
