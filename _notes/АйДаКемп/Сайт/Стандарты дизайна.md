## 1. Контрастность — основа всего

### Почему критично для нас
Аудитория — мамы 34–45 лет, с телефона, часто вечером или на ходу + сайт смотрят на улице под солнцем. Оба сценария убивают низкий контраст.

**Стандарт: WCAG 2.1 AA** минимум для всего текста. Для основного контента — стремиться к AAA.

### Минимальные соотношения контраста
| Тип текста | Минимум | Цель |
|---|---|---|
| Body текст (≥16px) | 4.5:1 | 7:1 |
| Крупный текст (≥24px bold / ≥18px) | 3.0:1 | 4.5:1 |
| UI-компоненты, иконки | 3.0:1 | 4.5:1 |
| Плейсхолдеры | 3.0:1 | — |

### ⚠️ Главная проблема — оранжевый #ec7c00
Белый текст на `#ec7c00` = **2.9:1 — ПРОВАЛ**. Самая частая ошибка.

**Решения:**
- Использовать `#ec7c00` только как фон кнопок **без текста** (иконка + цвет = достаточно)
- Если нужен текст на оранжевом → фон **#c45f00** (контраст 4.6:1 ✓)
- Для маленьких бейджей → текст **#7a3500** (тёмно-коричневый, контраст 6.8:1 ✓)

**Запрещено:**
- Белый текст на `#ec7c00` в производственном коде
- Оранжевый текст на светло-жёлтом/светло-оранжевом фоне

### Инструменты проверки
- [contrast-checker.com](https://contrast-checker.com) — два цвета → результат
- Chrome DevTools → Accessibility → Contrast ratio
- Figma плагин «Contrast»
- axe DevTools (расширение браузера)

**Правило:** перед деплоем нового компонента — запускать contrast-checker на все комбинации текст+фон.

## 2. Мобильная версия — приоритет #1

68% трафика с мобильных. Мобилка = основной интерфейс, десктоп — вторичный.

### Размеры текста — жёсткие минимумы
| Элемент | Минимум |
|---|---|
| Body текст | **16px** |
| Кнопки | **16px** |
| Secondary / подписи | **14px** |
| Placeholders | **14px** |
| Микро-лейблы (бейджи) | **12px** |

### Тач-цели
- Минимум **48×48px** для всех интерактивных элементов (Apple + Google standard)

### CTA-кнопки на мобиле
- Главная CTA → `width: 100%` на мобиле
- Отступы по бокам → 16–20px
- Sticky CTA снизу после скролла hero

**Запрещено:**
- CTA с `padding: 8px 12px` на мобиле (слишком мал тач-таргет)
- Два оранжевых CTA рядом

### Отступы и сетка на мобиле
| Элемент | Значение |
|---|---|
| Padding страницы (горизонталь) | 16–20px |
| Gap между секциями | 24–32px |
| Gap между карточками | 12–16px |
| Padding внутри карточки | 16–20px |

## 3. Читаемость под солнцем

На прямом солнце воспринимаемый контраст падает **втрое** от показателей contrast-checker. То что даёт 4.5:1 в темноте → на солнце ~1.5:1 = нечитаемо.

### Правила для "солнечного" дизайна
- Контраст текста → минимум **7:1** (не 4.5:1)
- Размер body текста → минимум **18px** (не 16px)
- Статусы → **текстом + цветом**, не только цветом
- Фоны → насыщенные тёмные, не полупрозрачные

### Практический тест
Открыть на телефоне, выйти на яркий свет (или минимальная яркость экрана). Читается = норма.

## 4. Применение цвета

### Архитектура цветов
Три независимые системы — смешивать нельзя:
- **АйДаКемп (лагерь):** `#060e1a` фон, `#ec7c00` акцент
- **АйДаКодить (школа):** светлая тема (уточнить)
- **Семантические:** `#22c55e` success, `#ef4444` error, `#f59e0b` warning

### Закон одного CTA
На каждом viewport — **ровно одна** оранжевая кнопка. Закон Хика: больше кнопок = паралич выбора = снижение конверсии.

- Главная кнопка → оранжевая
- Вторичная → outline или ghost
- Два оранжевых CTA рядом — **запрещено**

### Зелёный #0d2818 — только кросс-промо
Строго один раз на сайте школы — в блоке кросс-промо лагеря. Нарушение ломает систему.
- Для success состояний форм → `#22c55e` / `#dcfce7`
- `#0d2818` только в `CampPromo.astro`

## 5. Типографика

### Шрифты проекта
- **Manrope** — основной (заголовки, body, кнопки)
- **JetBrains Mono** — код, время, технические данные

### Масштаб размеров
| Роль | Размер | Weight |
|---|---|---|
| H1 | 32–48px (clamp) | 800 |
| H2 | 24–32px | 800 |
| H3 | 20–24px | 700 |
| Body large | 18px | 400 |
| Body | 16px | 400 |
| Secondary | 14px | 400–500 |
| Caption / Label | 12px | 600–700 |

### Line-height
| Тип | Значение |
|---|---|
| Заголовки | 1.1–1.25 |
| Body текст | **1.65–1.75** |
| Компактный текст (карточки) | 1.45–1.55 |

### Letter-spacing
- H1–H2: `-0.02em` до `-0.03em`
- Body: `0`
- Caption uppercase: `0.06–0.10em`
- Кириллица: не больше `0.05em`

## 6. Изображения и производительность

- Форматы: **AVIF > WebP > JPEG** (не PNG для фото)
- Hero: `loading="eager" fetchpriority="high"`
- Остальные: `loading="lazy"`
- Всегда указывать `width`, `height`, `alt`
- srcset для Retina (2x)

## 7. Компоненты — общие правила

### border-radius
- Обычные карточки/кнопки: **8–16px**
- Pill-кнопки (50px): **только на промо-лендингах** с игровой атмосферой

### Тени
```css
/* Попапы, дропдауны */
box-shadow: 0 8px 32px rgba(0,0,0,.15);

/* Hover карточек */
box-shadow: 0 4px 16px rgba(0,0,0,.1);

/* Свечение акцентов */
box-shadow: 0 0 20px rgba(236,124,0,.3);
```
Тени на тёмном фоне — не видно, не применять.

### Анимации
- JS анимации → `requestAnimationFrame`, не `setInterval`
- UI-реакции → не дольше **0.4s**
- Параллакс на мобиле — запрещён

## 8. Формы

- `font-size: 16px` у `input`, `textarea`, `select` — предотвращает zoom на iOS
- `min-height: 48px` у кнопки submit
- Маска телефона: `+7 (___) ___-__-__`
- Чекбокс согласия: checked by default + ссылка на политику
