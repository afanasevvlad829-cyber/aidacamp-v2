## Заметки для дизайн-агента

- **Тёмная тема** — сейчас не реализована. Если добавлять, нужен `prefers-color-scheme: dark` или js-toggle с `data-theme="dark"` на `<html>`.
- **Все иконки** — Bootstrap Icons через CSS (`<i class="bi bi-*">`). Список доступных: `src/data/icons-manifest.json`.
- **Никаких эмодзи** — запрещены в UI (правила CLAUDE.md).
- **Шрифты** — Manrope (основной) + JetBrains Mono (код). Подключены через Google Fonts.
