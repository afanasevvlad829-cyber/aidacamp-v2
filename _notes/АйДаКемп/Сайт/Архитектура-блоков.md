## Главная страница — 13 блоков

### 01. NAV — Навигация
**Компонент:** `Nav.astro`
**Элементы:**
- Лого + название (АйТи-лагерь · 7–14 лет)
- Пункты меню: О лагере, Смены 2026, Фото, FAQ, Команда, «...»
- Телефон с иконкой — кнопка уровень 2 (контурный)
- Мобиле: бургер-меню

**Кнопки:**
- Пункты меню → уровень 3 (серый нейтральный)
- Телефон → уровень 2 (контурный оранжевый)

---

### 02. HERO — Первый экран
**Компонент:** `Hero.astro`
**Фон:** тёмный `#0f1c2e` + живое фото детей за работой

**Десктоп:**
- Надпись-геолокация: «66 км от Москвы · смены июнь–август»
- H1: «Летний лагерь в Подмосковье, 7–14»
- Лид: «Каждый уедет с проектом и новыми друзьями.»
- Микро-вовлечение: «Вам — 14 дней для себя. Согласны? 👍 301»
- Теги: Python / Minecraft / AI / Бассейн (бейджи уровень 4)
- Доверие: ★ 5.0 · 6 лет работы · 1200+ детей
- CTA: кнопка «Смены 2026 ↓» → уровень 2 (контурный)

**Мобиле:**
- H1 + лид + микро-вовлечение
- Info-bar: «от 48 000 ₽ · ✓ Перезвоним за 10 минут»
- Форма: возраст (3 кнопки) + телефон + чекбокс
- CTA: «Забронировать место» → уровень 1 (залитый)
- Disabled: серая `bg-slate-200` пока не заполнено
- Подсказки под кнопкой: шаги + гарантии + чеклист

**Trust-bar (оба):**
- Тёмная полоска: «от 48 000 ₽ за 7 дней · 60% возвращаются · проживание включено · Трансфер — опция»

### 03. OCCUPANCY + FOUNDER — Занятость и доверие
**Компонент:** `Occupancy.astro`
**Два блока рядом (десктоп) / стек (мобиле):**

Левый — проверка мест:
- Иконка + «Проверить свободные места»
- «Данные обновляются в реальном времени»
- Кнопка «Проверить занятость» → уровень 2 (контурный)

Правый — цитата основателя:
- Фото Дарьи
- Цитата курсивом
- Имя + роль

---

### 04. ABOUT — «Это не ещё один лагерь»
**Компонент:** `About.astro`
**Элементы:**
- H2 с оранжевой полосой
- Лид-подзаголовок
- 3 фото-карточки с подписями (живые фото детей)
- Текст-крючок + кнопка «Узнать больше» → уровень 2 (контурный)

**Фото:** реальные дети за работой, разные сцены
**Важно:** фото — главный аргумент, не иллюстрация

---

### 05. JOURNEY — Как проходит смена
**Компонент:** `Journey.astro`
**Элементы:**
- H2 с оранжевой полосой
- Табы: «Программа» / «День в лагере» → уровень 3 (серый)
  - Активный таб: серый фон, тёмный текст (не оранжевый)
- Вкладка «Программа»:
  - H3: «Мы не играем в игры — мы их создаём»
  - Лид + 1 абзац body
  - 3 карточки: 7–9 / 10–12 / 13–14 лет
  - Подсказка: «Опыт не нужен»
- Вкладка «День в лагере»:
  - Расписание по часам
  - Описание занятий

---

### 06. ECONOMY — Телефон здесь зарабатывают
**Компонент:** `Economy.astro`
**Элементы:**
- H2 с оранжевой полосой
- H3 полужирный
- 1 абзац body
- 2 карточки: «Телефонное время» / «Коллективные события»
- Цитата (callout с оранжевой полосой)
- Callout-info: «Связь с ребёнком — через вожатого»
- BookingBar → уровень 2 (контурный) для «Перезвоните мне»

---

### 07. SHIFTS — Смены
**Компонент:** `Shifts.astro`
**Элементы:**
- H2 с оранжевой полосой
- Сетка карточек смен (4 основных + 2 коротких)
- Карточка смены:
  - Название + бейджи «Популярная» / «места есть» / «короткая» → уровень 4
  - Даты + количество дней
  - Кнопки «календарь» / «инфо» → уровень 3 (серый)
  - Описание (1–2 предложения)
  - Цена + «Питание включено»
  - Прогресс-бар занятости
  - CTA «Выбрать» → уровень 1 (залитый) только для горящей смены
  - Остальные «Выбрать» → уровень 3 (серый контур)
  - Гарантия: «Не понравится в первые 3 дня — вернём 50%»
- BookingBar после смен → уровень 2 (контурный)

### 08. PARENT-CTA — Вам тоже нужно лето без тревоги

**Элементы:**
- Тёмный блок `#0f1c2e`
- H2 (белый): «Вам тоже нужно лето без тревоги»
- Подзаголовок (серый)
- CTA «Выбрать смену ↓» → уровень 1 (залитый)

### 09. HACKATHON — Хакатон
**Компонент:** `Hackathon.astro`
**Элементы:**
- H2 с оранжевой полосой
- Описание (1 абзац)
- Роли: теги → уровень 4 (бейджи серые)
- Степпер 1→2→3→4:
  - Текущий → уровень 1 (залитый)
  - Остальные → уровень 2 (контурный)
- Тёмный блок «Что остаётся после» с чеклистом

### 10. GALLERY — Фото
**Компонент:** `Gallery.astro`
**Элементы:**
- H2 с оранжевой полосой
- Фильтры: Атмосфера / Бассейн / Спорт / Учёба / Питание → уровень 3 (серый)
  - Активный: серый фон, тёмный текст (не оранжевый)
- Сетка фото с lazy-load
- Хэштег #АЙДАКЕМП

**Фото — приоритет:**
- Реальные дети, не постановочные
- Разные активности, не только компьютеры
- Эмоции, командная работа, спорт

## Правила для SEO-лендинга

1. **H1** — точное вхождение ключевого запроса
2. **Hero** — тот же компонент, другой контент (заголовок, подзаголовок, теги)
3. **Shifts** — показывать только смены релевантные теме
4. **FAQ** — минимум 5 вопросов по теме страницы
5. **Фото** — добавить фото релевантные теме (например для /minecraft-lager — фото Minecraft-занятий)
6. **Кнопки** — та же система 4 уровней, без исключений
7. **SEO-Grid** — показывать смежные страницы, не все 16
