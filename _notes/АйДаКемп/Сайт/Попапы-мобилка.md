### ShiftModal — модалка смены

**Файлы:** `src/components/ShiftModal.astro` + `src/scripts/shift-modal.ts`

**Внешний вид на мобиле:**
- Панель выезжает **снизу экрана** (не по центру), занимает 85% высоты
- Сверху — серая ручка для свайпа
- Прокрутка внутри панели если контент длиннее экрана

**Триггеры открытия:**

| Действие | Вкладка |
|---|---|
| Тап по карточке смены | Описание |
| Кнопка «Календарь» на карточке | Календарь |
| Кнопка «Инфо» на карточке | Подробнее |
| Тап по строке в блоке «Проверить занятость» | Описание |

**Три вкладки:**
- **Описание** — название, даты, длительность, полоса занятости, цена, кнопка «Выбрать смену»
- **Календарь** — мини-календарь с подсвеченными днями смены
- **Подробнее** — программа по дням, возрасты, как работает AI

**Посыл:** дать всю информацию о смене без ухода со страницы — снизить трение перед бронированием

**Закрытие:**
- Кнопка ✕
- Тап на затемнённый фон
- **Свайп вниз > 80px по ручке** ← только мобилка
- При выборе «Выбрать смену» → закрывается, через 320ms открывается ShiftBookModal

**Анимация:** 300ms, панель выезжает снизу

### AgeBar — плашка выбора возраста ← ТОЛЬКО МОБИЛКА

**Файл:** `src/components/AgeModal.astro`  
**Класс:** `lg:hidden` — на десктопе не отображается вообще

**Где:** `fixed bottom-0 inset-x-0` — полоса по всей ширине снизу экрана

**Триггер:** через **8 секунд** после загрузки страницы  
**Один раз за сессию:** `sessionStorage.age_bar_shown`

```
┌────────────────────────────────────────────┐
│ Возраст   [7–9]   [10–12]   [13–14]    [✕] │
│ ████████████░░░░░░░░░░░ (отсчёт 20 сек)   │
└────────────────────────────────────────────┘
```

**Логика прогресс-бара:** убывает за 20 секунд, затем плашка сама скрывается

**Посыл:** пользователь уже 8 секунд на странице — предлагаем направить его к нужным сменам быстрым тапом

**При выборе возраста:** плашка закрывается + скролл к `#shifts`  
**Авто-скрытие:** через 20 сек  
**Анимация:** slideUp из-за нижнего края

**Файл:** `src/components/AgeOnboarding.astro`

  │  11–12 лет │   │  13–14 лет │
  └────────────┘   └────────────┘

           или пропустить →

**Посыл:** персонализировать путь с первого взаимодействия — скролл к нужным сменам без поиска

**При выборе:** `localStorage.user_age_group = '7-8'` → скролл к `#shifts`  
**Закрытие:** выбор возраста, ✕, «пропустить», тап вне карточки

### Nudge-тосты — всплывающие уведомления

**Файл:** `src/scripts/nudge.ts`

**Где:** выезжают снизу экрана, небольшой тост, живут **5 секунд** затем исчезают  
**Один раз за сессию** (`sessionStorage.nudge_shown`), одновременно только один

**По скроллу:**

| Скролл | Текст | Посыл |
|---|---|---|
| **30%** | 🔥 Смена 2 — самая популярная. Осталось 12 мест | FOMO, срочность |
| **60%** | 📸 Каждый день — фотоотчёт для родителей | Снять тревогу |
| **80%** | ✅ Лицензированный туроператор РТО 025773 | Доверие, безопасность |

**По времени:**

| Задержка | Текст | Посыл |
|---|---|---|
| **+30 сек** | ⏰ Раннее бронирование — скидка до 10% | Действовать сейчас |
| **+60 сек** | 👨‍👩‍👦 Более 200 семей уже выбрали АйДаКемп | Социальное доказательство |
| **+90 сек** | 🎓 Авторы учебника по Python — наши преподаватели | Экспертиза |

> **Exit intent — только десктоп**, на мобилке не работает (нет mouseout)

**Закрытие:** ✕, или авто через 5 сек

## Sticky CTA — мобилка

**Файл:** `src/components/StickyCta.astro`  
**Класс:** `lg:hidden` — только мобилка  
**Появляется:** когда `#hero` уходит из видимости (IntersectionObserver, порог 10%)

### Состояние 1: Развёрнутый бар

**Где:** `fixed bottom-0 inset-x-0` — тёмная полоса на всю ширину снизу

```
┌──────────────────────────────────────────┐
│  📞 Позвонить    💚 WhatsApp   💙 Telegram   ✕ свернуть │
└──────────────────────────────────────────┘
```

Фон: `bg-slate-900/80 backdrop-blur-md` (тёмный полупрозрачный)

**Посыл:** быстрый доступ к трём каналам связи одним тапом

### Состояние 2: Свёрнутый bubble

**Где:** `fixed bottom-5 right-4` — круглая кнопка ⌀48px, тёмный фон

- Иконка: телефон
- Тап → разворачивается обратно в бар

### Переключение состояний

```
Hero видим           → ничего не показывается
Hero ушёл из вида    → появляется бар (развёрнут)
Тап «свернуть»       → переходит в bubble
Тап на bubble        → снова бар
```

## Хронология показов на мобилке

```
0 сек     → Cookie banner (если не принят ранее навсегда)
0 сек     → IntersectionObserver запущен для #hero

+3 сек    → AgeOnboarding (если не видел ранее навсегда)
            ИЛИ при скролле 25% — что наступит раньше

+8 сек    → AgeBar (нижняя полоска, если не было в сессии)

+30 сек   → Nudge «Раннее бронирование»
+60 сек   → Nudge «200 семей»
+90 сек   → Nudge «Авторы учебника»

─── при скролле ─────────────────────────────────────

~10%  → Hero ушёл → появляется StickyCta (нижний бар)
 25%  → AgeOnboarding (если таймер ещё не успел)
 30%  → Nudge «Смена 2 — популярная, 12 мест»
 60%  → Nudge «Фотоотчёт»
 80%  → Nudge «Туроператор»

─── по действию ─────────────────────────────────────

Тап «Проверить занятость» → loader 900ms → список смен
Тап по строке занятости   → ShiftModal (Описание)
Тап по карточке смены     → ShiftModal (Описание)
Кнопка «Календарь»        → ShiftModal (Календарь)
Кнопка «Инфо»             → ShiftModal (Подробнее)
Кнопка «Выбрать»          → ShiftBookModal
ShiftModal «Выбрать смену» → [320ms] → ShiftBookModal
Успешная отправка          → ReferralModal
Неполная форма             → ValidationModal
Тап на фото                → Gallery Lightbox
Кнопка «Смотреть книгу»   → TeamBookModal
```

## Хранилище состояний

| Ключ | Тип | Что означает |
|---|---|---|
| `age_onboarding_shown` | `localStorage` | AgeOnboarding показывался (навсегда) |
| `user_age_group` | `localStorage` | Выбранный возраст (`7-8`, `9-10`, `11-12`, `13-14`) |
| `age_bar_shown` | `sessionStorage` | AgeBar показан в этой сессии |
| `nudge_shown` | `sessionStorage` | JSON-массив ID показанных nudge-ов |
| `cookieAccepted` | `localStorage` | Cookie banner принят |
