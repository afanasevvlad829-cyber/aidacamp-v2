Анализ и рекомендации

✅ CR вырос: 0.5% → 1.4% от скролла
За апрель 2026 итоговая конверсия scroll_25 → lead выросла вдвое. ShiftModal открывается в 29% случаев после выбора возраста (было 4–5%). Новый ShiftModal с вкладками работает.

Данные ~300 scroll_25 → ~105 age_select → ~30 ShiftModal → ~4 lead за 14 дней.
🚨 Главный отвал: возраст выбран → смена не открыта (-71%)
~105 выбирают возраст на десктопе, только ~30 открывают ShiftModal. 75 человек теряются.

Критично После AgeOnboarding пользователь видит большую сетку карточек — нет визуального указания «вот твои смены».

Идея Подсветить нужные карточки (border-orange, остальные opacity-50) — на десктопе 2-колоночная сетка, эффект будет заметен.
🖱 Exit Intent — нужна персонализация
Уникален для десктопа, срабатывает один раз. Сейчас общий текст.

Улучшение Читать возраст из localStorage → «Для детей 10–12 лет: Смена 2 — 4 места. Записаться?» + CTA-кнопка вместо просто текста.
⚠️ Bubble — нет данных по кликам
Клики по оранжевому bubble не отслеживались явной целью Метрики. Нельзя сказать конвертит или нет.

Сделать Добавить trackGoal('bubble_click') на открытие bubble-панели — тогда будет ясно удалять или оставлять.
✅ Что хорошо работает на десктопе
• Средний скролл 64–78% — десктоп читает внимательнее мобилки
• Dead clicks 6–10% — приемлемо
• ShiftModal по центру с табами — удобнее чем мобильный swipe
• Active time 48–74 сек — хорошее вовлечение
💡 Приоритеты для десктопа
1. Высокий Подсветка карточек смен после выбора возраста

2. Высокий Персонализированный exit intent с localStorage + CTA

3. Средний Добавить trackGoal на bubble_click — узнать реальную цифру

4. Средний WhatsApp/Telegram в ShiftBookModal как альтернатива телефону
