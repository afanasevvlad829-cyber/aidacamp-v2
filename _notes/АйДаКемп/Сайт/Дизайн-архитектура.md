## 1. Общие понятия и правила

### Философия
Один акцентный цвет — оранжевый. Всё остальное — тихое. Взгляд пользователя управляется через иерархию, а не через украшение.

### Главный принцип распределения внимания
- **Оранжевый залитый** = деньги / действие / конверсия
- **Оранжевый контурный** = интерес / навигация / вторичное действие
- **Серый** = ориентирование / утилиты
- **Невидимый** = информация / статус

Максимум **2 залитых оранжевых элемента** одновременно на экране.

### Система кнопок — 4 уровня

| Уровень | Стиль | Когда использовать | Примеры |
|---|---|---|---|
| 1 — Кричит | Залитый `#ec7c00` | Деньги, бронь, заявка | «Забронировать место», «Выбрать», «Отправить заявку» |
| 2 — Говорит | Контурный, фон `#fff0e0`, рамка `#ec7c00` | Конверсионные, но не срочные | «Перезвоните мне», «Проверить занятость», «Узнать больше» |
| 3 — Шепчет | Нейтральный серый | Навигация, табы, утилиты | Табы, фильтры FAQ, «календарь», меню шапки |
| 4 — Молчит | Бейджи, маркеры | Только статус, не кликабельны | «Популярная», «места есть», роли хакатона |

**Правило disabled:** всегда серая `bg-slate-200 text-slate-400`. Никогда не оранжевая с opacity.

### Решения по доступности (A11y)

**A11y Lighthouse: 96/100 — принято, не трогаем.**
Оранжевый `#ec7c00` на белом даёт контраст 2.81:1 (норма 4.5:1 для мелкого текста).
Решение: оставить бренд-цвет как есть. 96 — отличный результат, смена цвета навредит бренду больше чем даст баллов.

**Best Practices: 77 — не трогаем.**
Минус идёт от Яндекс.Метрики, Top.Mail.Ru, Microsoft Clarity. Убирать счётчики нельзя.

### Законы UX / CRO

| Закон | Как применяем |
|---|---|
| Fitts | Кнопки мобиле полная ширина ≥44px |
| Hick | Форма 2 поля, модалка 3 варианта |
| Von Restorff | Максимум 2 залитых → уникальность работает |
| Fogg | Мотивация (фото, отзывы) + Возможность (2 поля) + Триггер (занятость, гарантия) |
| Чалдини | «Согласны» — микро-обязательство перед заявкой |
| Jakob | Единая система кнопок по всему сайту |
