### Cron

| Время | Задача |
|---|---|
| `0 6-21 * * *` | `/opt/etl/run-etl.sh` — полный ETL (Direct + Metrika + Clarity) каждый час днём |
| `5 6-21 * * *` | `vk-sync.py` — sync VK Ads по кампаниям |
| `@daily` | `/opt/browser-agent/site-snapshot.sh` — инкрементальный снапшот сайта |

### MCP-сервер (`/opt/mcp/mcp-server.mjs`)

- HTTP endpoint: `https://dev.aidacamp.ru/mcp` (Bearer auth)
- Дашборд: `https://dev.aidacamp.ru/mcp/dashboard`
- Кнопки ETL в дашборде вызывают `POST /mcp/api/etl` с `type=vk|etl|all`. Тянут `today-7 → today`, Clarity пропускается через `NO_CLARITY=1`
- Инструменты: ssh, stats, photos, browser_agent, clarity, pagespeed, vk/direct CRUD, files

### Site-snapshot

`https://dev.aidacamp.ru/screenshots/site-snapshot/`:
- `content.json` — контент всех 20 страниц + поле `"generated"` с датой
- `summary.md` — сводка
- `screenshots/desktop-{name}.png`, `mobile-{name}.png`
- Обновляется при каждом деплое
