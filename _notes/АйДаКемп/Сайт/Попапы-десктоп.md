### ShiftModal — модалка смены

**Файлы:** `src/components/ShiftModal.astro` + `src/scripts/shift-modal.ts`

**Внешний вид на десктопе:**
- Панель появляется **по центру экрана** (не снизу)
- Карточка фиксированной ширины, тёмный backdrop
- Ручки для свайпа нет — она здесь не нужна

**Триггеры открытия:**

| Действие | Вкладка |
|---|---|
| Клик по карточке смены | Описание |
| Кнопка «Календарь» на карточке | Календарь |
| Кнопка «Инфо» на карточке | Подробнее |
| Клик по строке в блоке «Проверить занятость» | Описание |

**Три вкладки:**
- **Описание** — название, даты, длительность, полоса занятости, цена, кнопка «Выбрать смену»
- **Календарь** — мини-календарь с подсвеченными днями смены
- **Подробнее** — программа по дням, возрасты, как работает AI

**Посыл:** дать всю информацию о смене без ухода со страницы — снизить трение перед бронированием

**Закрытие:**
- Кнопка ✕
- Клик на затемнённый фон
- Клавиша `Escape`
- *(свайп вниз — только мобилка, на десктопе отсутствует)*
- При выборе «Выбрать смену» → закрывается, через 320ms открывается ShiftBookModal

**Анимация:** 300ms, панель появляется с небольшим смещением вниз (`md:translate-y-4 → md:translate-y-0`) + fade in

### Exit Intent Nudge ← ТОЛЬКО ДЕСКТОП

**Файл:** `src/scripts/nudge.ts`

**Где:** тост-уведомление, выезжает снизу экрана (как все nudge-тосты)

**Триггер:** курсор уходит за верхний край экрана (`mouseout`, `e.clientY ≤ 0`)  
**Условие:** `window.matchMedia('(min-width: 1024px)').matches` — строго только десктоп  
**Один раз за сессию:** `sessionStorage.nudge_shown` содержит `'exit'`

```
👋 Уже уходите? Оставьте номер — расскажем подробнее  [✕]
```

**Посыл:** перехватить намерение закрыть вкладку, удержать — предложить не уйти, а поговорить  
**Живёт:** 5 секунд, затем исчезает; закрывается кнопкой ✕

> ⚠️ На мобилке события `mouseout` нет — триггер не срабатывает никогда

### AgeOnboarding — «Сколько лет ребёнку?»

**Файл:** `src/components/AgeOnboarding.astro`

**Где:** `fixed inset-0 z-[60]` — полноэкранный оверлей, карточка `max-w-[380px]` по центру, тёмный фон `#07101e`

**На десктопе:** карточка компактная по центру большого экрана, 4 кнопки в сетке 2×2

**Два триггера (что наступит раньше):**
1. **+3 секунды** после загрузки
2. **Скролл ≥ 25%** страницы

**Один раз навсегда:** `localStorage.age_onboarding_shown`

```
                              [✕]
       Сколько лет ребёнку?

  ┌────────────┐   ┌────────────┐
  │   7–8 лет  │   │  9–10 лет  │
  └────────────┘   └────────────┘
  ┌────────────┐   ┌────────────┐
  │  11–12 лет │   │  13–14 лет │
  └────────────┘   └────────────┘

           или пропустить →
```

**Посыл:** персонализировать путь с первого взаимодействия — скролл к нужным сменам без поиска

**При выборе:** `localStorage.user_age_group = '7-8'` → скролл к `#shifts`  
**Закрытие:** выбор возраста, ✕, «пропустить», клик вне карточки, `Escape`

## Sticky CTA — десктоп

**Файл:** `src/components/StickyCta.astro`  
**Элемент:** `#desktop-sticky` — только `lg:flex` (скрыт на мобилке через `lg:hidden` у мобильных вариантов)  
**Появляется:** когда `#hero` уходит из видимости (IntersectionObserver, порог 10%)

### Состояние 1: Свёрнутый bubble (по умолчанию)

**Где:** `fixed right-5 bottom-6` — правый нижний угол  
**Размер:** `h-14 w-14` (⌀56px), `rounded-full`  
**Цвет:** `bg-[#ec7c00]` — оранжевый с тенью `shadow-[0_4px_24px_rgba(236,124,0,0.4)]`  
**Hover:** масштабируется `scale-105`, тень усиливается

- Иконка: белый телефон
- Пульсирующая точка в правом верхнем углу: `animate-ping bg-orange-300` поверх `bg-orange-200`

### Состояние 2: Развёрнутая панель

**Где:** карточка `w-[220px]` над bubble, `bottom-[68px] right-0`  
**Фон:** белый `bg-white`, тень `shadow-[0_12px_40px_rgba(15,23,42,0.18)]`, скруглённая `rounded-[16px]`

```
┌─────────────────────────────┐
│ Свяжитесь с нами            │
│                             │
│ 📞 +7 (495) 128-44-29       │
│ 💚 WhatsApp                 │
│ 💙 Telegram                 │
└─────────────────────────────┘
         [🟠 кнопка ⌀56px]
```

**Анимация открытия:** `scale-95 opacity-0` → `scale-100 opacity-100`, 200ms, `origin-bottom-right`

**Закрытие панели:**
- Повторный клик на bubble
- Клик в любом другом месте страницы

### Переключение состояний

```
Hero видим           → #desktop-sticky скрыт полностью
Hero ушёл из вида    → появляется оранжевый bubble
Клик на bubble       → разворачивается панель
Клик вне панели      → панель сворачивается
```

## AgeBar — не показывается на десктопе

**Причина:** `lg:hidden` — CSS класс полностью скрывает элемент на ≥ 1024px  
**Аналог для десктопа:** AgeOnboarding (появляется на всех платформах)

## Хронология показов на десктопе

```
0 сек     → Cookie banner правый нижний угол (если не принят ранее навсегда)
0 сек     → IntersectionObserver запущен для #hero

+3 сек    → AgeOnboarding (если не видел ранее навсегда)
            ИЛИ при скролле 25% — что наступит раньше

+30 сек   → Nudge «Раннее бронирование»
+60 сек   → Nudge «200 семей»
+90 сек   → Nudge «Авторы учебника»

─── при скролле ─────────────────────────────────────

~10%  → Hero ушёл → появляется оранжевый StickyCta bubble
 25%  → AgeOnboarding (если таймер ещё не успел)
 30%  → Nudge «Смена 2 — популярная, 12 мест»
 60%  → Nudge «Фотоотчёт»
 80%  → Nudge «Туроператор»

─── exit intent ─────────────────────────────────────

Курсор → верхний край браузера → Nudge «Уже уходите?»

─── по действию ─────────────────────────────────────

Клик «Проверить занятость»  → loader 900ms → список смен
Клик по строке занятости    → ShiftModal (Описание)
Клик по карточке смены      → ShiftModal (Описание)
Кнопка «Календарь»          → ShiftModal (Календарь)
Кнопка «Инфо»               → ShiftModal (Подробнее)
Кнопка «Выбрать»            → ShiftBookModal
ShiftModal «Выбрать смену»  → [320ms] → ShiftBookModal
Успешная отправка            → ReferralModal
Неполная форма               → ValidationModal
Клик на фото                 → Gallery Lightbox (с ← → навигацией)
Кнопка «Смотреть книгу»     → TeamBookModal
Клик на StickyCta bubble     → разворачивается панель контактов
```

## Хранилище состояний

| Ключ | Тип | Что означает |
|---|---|---|
| `age_onboarding_shown` | `localStorage` | AgeOnboarding показывался (навсегда) |
| `user_age_group` | `localStorage` | Выбранный возраст (`7-8`, `9-10`, `11-12`, `13-14`) |
| `nudge_shown` | `sessionStorage` | JSON-массив ID показанных nudge-ов (включая `exit`) |
| `cookieAccepted` | `localStorage` | Cookie banner принят |
