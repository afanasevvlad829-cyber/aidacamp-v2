## Что не подменяется

- **Ретаргет Директ** (retarget_hot/warm/content/bounce) — объявления ведут на якоря (#shifts, #program, #price), hero не в видимой зоне при загрузке. Подмена H1 не имеет смысла.
- **VK числовые utm_content** (`214434612`, `214774477` и др.) — старые кампании без named ключей. Видят дефолт.

## Как добавить новый вариант

1. Открыть `src/components/Hero.astro`, найти объект `variants` (ищи `var variants = {`).
2. Добавить строку: `myKey: { title: '...', subtitle: '...' }` (subtitle опционально).
3. Обновить эту таблицу.
4. Деплой: `./scripts/deploy.sh dev` → проверить → `./scripts/deploy.sh prod`.
