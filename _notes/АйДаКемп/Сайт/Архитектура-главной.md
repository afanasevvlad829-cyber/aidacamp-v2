## Принципы структуры (AIDA)

```
Attention  → Хиро (заголовок + фото + форма)
Interest   → О лагере + Как проходит смена + Телефон
Desire     → Смены (прогресс-бары, цены, гарантия) + Хакатон + Фото + Видео
Action     → Booking-bar 1 + Booking-bar 2 + «Вам тоже нужно лето»
Trust      → Отзывы + FAQ + Команда + Размещение
```

## Архитектура для SEO-лендинга (шаблон)

SEO-лендинг = сокращённая версия главной с фокусом на ключевую фразу.

### Структура блоков SEO-лендинга

| # | Блок | Отличие от главной |
|---|---|---|
| 01 | Хиро | Заголовок = ключевая фраза страницы |
| 02 | Trust-bar | Тот же |
| 03 | Что такое [тема] | Уникальный текст под страницу, 150-200 слов |
| 04 | Программа | Тот же блок из Journey |
| 05 | Чем отличается от [конкурент/формат] | Уникальный, 100 слов |
| 06 | Смены | Тот же Shifts |
| 07 | Booking-bar | Тот же |
| 08 | Фото | 6-9 фото по теме (фильтр) |
| 09 | Отзывы | 3 карточки |
| 10 | FAQ | Отфильтрованные вопросы по теме |
| 11 | SEO-карточки | Ссылки на смежные страницы |
| 12 | Футер | Тот же |

### Что даёт расширенная структура
- Больше текста = лучше индексация
- Фото по теме = уникальность страницы
- Уникальные FAQ = длинные ключи (long-tail)
- Внутренние ссылки = перелинковка
