# SEO-сервисы: полный инструментарий и протоколы MCP

> Инвентаризация 2026-06-12. Все инструменты доступны через `mcp__aidacamp-tools__run(service, action, params)`.
> Код обработчиков: `/opt/mcp/lib/run/{topvisor,arsenkin,mutagen,webmaster,wordstat}.mjs` на VPS.
> Роли в конвейере: Арсенкин (частота: что хотят) × Мутаген (strong: что достижимо) × Топвизор (позиция: где мы) → классификация фразы → волна → через 7 дней Топвизор снова → оценка. Финальный судья — клики из Вебмастера.

## Топвизор (service="topvisor") — позиции и сниппеты

Что берём: семантическое ядро проектов + регулярные замеры позиций. «Линейка» конвейера: база до волны → сравнение через 7 дней.

Действия MCP: `balance`, `projects`, `folders`, `groups`, `keywords`, `positions`, `check`, `snippets`.

- `positions` — история позиций: params `project_id`, `date1`, `date2`, `regions_indexes` (aidacamp: [0], icepartners: [1])
- `check` — запустить замер. Внутри формат `edit/positions_2/checker/go` с `{"filters":[{"name":"id","operator":"EQUALS","values":[PROJECT_ID]}]}` — другие форматы API отвергает
- `snippets` (добавлено 12.06.2026) — наши сниппеты в выдаче (`snippet_title`, `snippet_body`) для CTR-аудита: чем мы выглядим в SERP на дату замера. Требует включённого сохранения сниппетов в настройках проекта
- `keywords` add — `name` СТРОКОЙ = 1 фраза за вызов, `to_id` = группа; del — filters id IN
- Выбор живого проекта среди легаси — по полям `update`/`on` в `projects`

Проекты: aidacamp **11807186** · codims **28354270** (легаси 24490079) · icepartners **28585795** (легаси 6988613, 1408610).

Платный по балансу — замеры запускаем вручную до/после волн, не по расписанию.

## Арсенкин (service="arsenkin") — выдача, частоты, LSI

Что берём: содержимое выдачи и спрос. Самый широкий набор инструментов.

Действия MCP (через `TOOL_MAP`):
- `top_export` — ТОП-100 выдачи по фразе: кто стоит (агрегаторы/конкуренты/мы)
- `wordstat` — частотность (кэш 24ч)
- `lsi` — LSI-слова и подсветки Яндекса: ядро механики «дожима» страниц поз.11–30
- `clustering` — какие фразы закрываются одной страницей
- `suggest` — поисковые подсказки: добор хвостов семантики
- `indexation` — проверка индексации списка URL
- `copyrighters` — авто-ТЗ на текст: медианные объёмы и вхождения у ТОПа (для «построить» страниц)
- `check_h` — парсинг Title/H1–H6 конкурентов: на фоне чего проигрывает наш сниппет (CTR-волны)
- `paa` — People Also Ask (идеи FAQ-блоков)
- `iks` — ИКС Яндекса доменов
- `ai_serp` — AI-ответы Алисы в выдаче
- `commercial_intent` — коммерциализация запросов

Протокол: асинхронный `action="set"` (params `{tool, data}`) → `task_id` → `action="get"`; короткие — `run_sync` или имя инструмента напрямую. Батчи ≤100 фраз, паузы 10–15с, 429 → бэкофф.

⚠️ Грабли: **дефис в запросе запрещён** («wi-fi для офиса» → «wi fi для офиса», маппинг назад вручную). Без API у Арсенкина: competitors, keyword_metrics, serp_features, возраст документов (проверять руками в веб-интерфейсе).

## Мутаген (service="mutagen") — конкурентность

Что берём: одну цифру strong (1–25+) — «фильтр реальности» для частоты. Из частота × strong рождается зелёная зона: спрос есть, конкуренции нет.

Действия MCP: `balance`, `check` (синхронно), `check_new`/`check_get` (асинхронно: POST `check_key.new {key}` → `task_id` → `check_key.get`), `parser_mass_new`/`parser_mass_get`/`parser_mass_list` (массовый парсинг Wordstat), `suggest_new`/`suggest_get` (**хвосты запросов** — добор НЧ-семантики).

Калибровка порога strong под силу сайта — по чемпионам (фразы, где сайт уже в ТОП-10): codims пробивает ≤22 (взрослый домен), aidacamp ≤14, icepartners стартовая ≤10 (молодой). Платный за фразу — гоняем топ ядра по частоте, не всё.

## Вебмастер (service="webmaster") — клики и индексация

Финальный судья: позиции без кликов ничего не стоят (правило «клики > позиции трекера»).

Действия MCP: `hosts`, `queries` (клики/показы/CTR по запросам и страницам), `recrawl` (переобход, квота ~750/сут), `indexing`, `sitemaps`, `ping_sitemap`, `errors`.

Протокол: токен строго `WEBMASTER_TOKEN`, user_id **19303961**, формат host_id `https:домен:443`. Подтверждены: aidacamp.ru, codims.ru, icepartners.ru (+www).

## Cloud Wordstat (service="wordstat") — официальные частоты

Действия MCP: `frequency`, `dynamic` (динамика спроса по месяцам — сезонность!), `regions` (география спроса), `suggest`.

Протокол: `searchapi.api.cloud.yandex.net/v2/wordstat/topRequests`, заголовок `Api-Key` (ключ AQVN… из `/opt/aistudio/.env`) + `folderId` (b1g…). Дополняет Арсенкина: официальный источник, без парсинга.

## Сценарии: какой инструмент когда

- **Новая волна на сайт**: topvisor keywords (ядро) → arsenkin wordstat (частоты) → mutagen check (strong топа по частоте) → topvisor positions (база) → классификация на зоны → волна
- **CTR-аудит**: webmaster queries (CTR vs медиана бакета позиций) → topvisor snippets (как мы выглядим) → arsenkin check_h + top_export (на фоне кого проигрываем) → правки description-first, title только аддитивно
- **Дожим поз.11–30**: arsenkin lsi (подсветки) → вписать в текст → recrawl
- **Построить страницу (зелёная зона)**: arsenkin copyrighters (ТЗ по ТОПу) + paa (FAQ) → страница → recrawl → таймер замера 7 дней
- **Добор семантики**: arsenkin suggest + mutagen suggest (хвосты) + wordstat dynamic (сезонность)
- **После волны**: webmaster recrawl (новые/правленые URL) → systemd-таймер +7 дней → topvisor check → сравнение с базой

## Чего у этого стека НЕТ (не закрывается сервисами)

Ссылки и репутация (каталоги, Я.Карты), поведенческие факторы (~60% веса Яндекса — смотрим Метрику и Clarity), E-E-A-T и коммерческие факторы, физадрес (блокер виджета Карт aidacamp), время на доверие к молодому домену. Снапшоты чужих сниппетов целиком — только частично через check_h/top_export.
