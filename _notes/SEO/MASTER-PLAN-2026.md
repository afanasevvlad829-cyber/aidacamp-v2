## 1. Север (North Star) и KPI

**Главная цель:** заявки на смену. Метрика Goal **`541048270`** (отправка формы age_select) — критичная конверсия, мониторится во всех SERP-экспериментах.

**KPI по фазам:**
- Клики/мес из органики (Вебмастер) — рост.
- Заявки (Goal 541048270) из органики — рост.
- TOP-10 по приоритетным кластерам (IT-ниша, «2026»+гео) — удержание/рост.

## 3. Три столпа стратегии

### Столп A — Технический фундамент (поддержка)
В основном сделано (title ≤58, schema, sitemap/robots/Clean-param, CWV, IndexNow, Partytown забанен). Режим — **поддержка, не переделка**. Новые страницы проходят те же стандарты.

### Столп B — Контент и интент (главный драйвер роста)
**Принцип: 1 интент = 1 страница.** Где играем и где нет:
- ✅ **IT-ниша** (поз.1–5, CTR высокий) — инвестировать. Уникальное преимущество, агрегаторы тут слабы.
- ✅ **«2026» + гео** (Подмосковье, города МО, гиперлокаль «Наро-Фоминск») — устойчивы к апдейтам, обновлять ежегодно.
- ✅ **Длинный хвост / НЧ** (348 без страницы, 506 вне TOP-100) — фабрика, но по данным (см. фазы).
- ❌ **Широкие транзакционные** («детский лагерь», «летние лагеря») — НЕ долбить: агрегаторы непробиваемы ссылками, виджет Карт отбирает клики (~0% CTR при поз.7–12). Заходить только через нишу/гео/возраст.
- 🔧 **Разгрузка главной** (#10): усилить тонкие цели → переключить ранжирование на них → главная перестаёт «качать».

### Столп C — Поведенческие (SXO) + E-E-A-T + репутация (Яндекс ~60%)
- **Поведенческие** (CTR в выдаче, dwell, pogo-sticking, bounce) — часть ранжирования. Clarity = инструмент (rage/dead clicks, scroll). РСЯ-группа `books` (bounce ~85%) портит ПФ — чистить.
- **E-E-A-T (YMYL — дети):** фото педагогов с именами, лицензия, отзывы со ссылкой на Я.Карты, `/founders`.
- **Репутация/ссылки:** incamp.ru (главная ссылка ✅), Я.Карты/2GIS отзывы, реестр МО `camp.mosreg.ru`, бесплатные каталоги.

### Фаза 1 — Низкорисковые победы (параллельно с измерением) 🟢
1. ✅ **СДЕЛАНО (07.06, PR #576, задеплоено)** — URL-свичи «лагерь в подмосковье»→`/detskiy-lager-podmoskove/`, «лагерь для школьников»→`/lager-dlya-shkolnikov-na-leto/`: перелинковка точным анкором, без трогания главной; статус ключей в `seo_url_switch_map` = `relinked`.
2. ✅ **СДЕЛАНО (07.06, PR #574, задеплоено)** — Корневой фикс шаблона фабрики: добавлена `stripYear()` в `seo-factory.js`, двойной «2026 2026» устранён на всех прогонах.
3. ✅ **СДЕЛАНО (07.06, PR #578)** — Гео-класс **здоров** (1400+ кликов/мес, позиции 6–10); `noindex` тонких неприменим. Реальная проблема — каннибализация дублей: фабрика плодила страницу по городу поверх уже существующей. Решение: дедуп в `seo-factory.js` (не генерирует страницу города, если она уже есть); 2 тонких дубля закрыты `canonical+noindex` (`/detskiy-lager-istra-moskovskaya-oblast`→`/lager-istra`, `/lager-elochki-domodedovo`→`/lager-domodedovo`). Наро-Фоминск (обе в топе, 199+71 клика) **не трогали**. Осталось: title-фикс `/lager-odintsovo` и `/lager-kolomna` (0 CTR при показах) — **отложено** (вероятно виджет Карт, см. блокер физадреса).
4. **РСЯ `books`** — почистить (bounce 85% портит ПФ).

## 5. Гардрейлы (жёсткие правила)
- **Клики > позиции** трекера при оценке.
- **Не трогать TOP-10 запросы главной** — их законная зона.
- **Никакого дубль-контента** (один шаблон на N страниц = риск Баден-Бадена). Усиление — только уникальный per-page текст.
- **Широкие агрегаторные запросы не долбить** — заходить через нишу/гео.
- **Фабрика — PR на ревью**, не авто-мерж (урок `seo_kaizen`).
- **Вся разработка агентами** — в изолированном Docker-контейнере non-root через `./scripts/agent-docker.sh` (правило №1), авторизация по подписке (`CLAUDE_CODE_OAUTH_TOKEN`); `vps-start-agent.sh` устарел. Прод-деплой — владельцем, из чистого worktree.
- **Бренд:** голос Дарьи (мама-подруга), без педагогических терминов/рекламы; вычет «до 5 434 ₽» (макс, 14 дн), не универсально; banned-words (единиц/баллов→рубли).
