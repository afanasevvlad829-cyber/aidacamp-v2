# 📐 SEO-конвейер: переносимая методика (выведена на aidacamp.ru, июнь 2026)

> Плейбук для раскатки на любой сайт (первый кандидат — codims.ru). Каждый шаг проверен на практике 08–11.06.2026; результаты и грабли — в `KEYWORD-STRATEGY-2026-06.md`, `MASTER-ANALYSIS-2026-06-08.md`, протоколы API — в «Библиотека знаний/SEO — основные правила» §Инструментальный стек.

## 0. Принципы (не нарушать)
1. **Клики > позиции трекера.** Решения — по Вебмастеру (показы/клики/CTR), позиции — вторичный сигнал.
2. **Факты, не гипотезы.** Любая цифра на странице (цены, даты, расстояния, вычеты) — из единого источника данных + build-страж дрейфа.
3. **Не трогать работающее:** кликающие запросы главной/чемпионов неприкосновенны; title — только аддитивно (без удаления слов портфеля).
4. **Широкие агрегаторные не долбить в лоб** (strong ≥15) — только хвост/свичи/перелинковка.
5. Всё через PR + CI-гейт (required build-чек, enforce_admins) + лог изменений.

## 1. Полный кейворд-аудит (1 день)
Вход: проект Топвизора + Вебмастер + Wordstat + Mutagen.
1. **Чистка трекера:** удалить чужие бренды/форматы; «мёртвый НЧ» = нет ТОП-100 ни в одной дате выгрузки × Wordstat base <5 → удалить из Топвизора + `is_noise=true` в БД (история сохраняется).
2. **Частоты всех живых** — Arsenkin wordstat батчами по 100 (пауза 10–15с).
3. **Mutagen strong** — топ-100..150 по частоте среди не-ТОП10.
4. **Классификация каждой фразы:** сегмент (ниша/гео/возраст/инфо/широкий) × действие:
   - `держать` (ТОП-10) · `дожать` (поз.11–30) · `усилить/построить` (strong≤10, спрос 50+) · `хвост-вместо-лба` (strong≥15 при freq>500) · `индексация/наблюдать`.
5. **Пороги Mutagen (калибровать по своим чемпионам!):** strong ≤10 — брать; 11–13 — работать; ≥15 — не в лоб. Калибровка aidacamp: своя страница в ТОП-4 имела strong=7; пробитый хвостом запрос — strong=15.

## 2. Главные фронты (по убыванию ROI)
**A. «Дожать» поз.11–30** — обычно крупнейший скрытый актив (у aidacamp: 133 запроса, вкл. 59K-частотник на поз.17).
Механика на страницу: Arsenkin `sp` (подсветки/LSI ТОП-20) → вплести ОТСУТСТВУЮЩИЕ леммы 1–2 предложениями в существующие секции (анти-Баден-Баден: без повторов точных форм) → 1–2 входящих точных анкора с релевантных страниц → переобход. ВАЖНО: сперва проверить, каким URL ранжируется запрос — если главной, см. фронт C.
**B. CTR-аудит ТОП-1..3** — построить СВОЮ кривую «позиция → медианный CTR» по Вебмастеру; отстающие = CTR < 50% медианы своего бакета при imp≥100. Чинить сниппет: description свободно (не ранжирует), title — только аддитивно. Поз.4+ при медиане ~0% не трогать (виджет Карт). У aidacamp нашлось ~2 000 потерянных кликов/мес на 6 страницах.
**C. Разгрузка главной (keep_home-пилот)** — запросы, где главная поз.11–17 и ~0 кликов: усилить выделенный носитель (точный title/H1+LSI) + 2–3 точных анкора с ДРУГИХ страниц; главную не редактировать вообще. Пилот 3 запроса → замер 7–14 дней → волна.
**D. Реальные дыры** — через Wordstat topRequests по сид-фразам ниши: только то, где сайта нет в выдаче совсем И strong≤10 И интент наш. Обычно мало (у aidacamp: 1 статья-разводка + 1 exact-match лендинг из ~290 «кандидатов» — остальное мусор ассоциаций).

## 3. Недельный цикл (постоянно)
- Переобход всех `in_index=false` (квота Вебмастера ~500+/сут) + новые страницы в день деплоя.
- Дельта Топвизора по волнам; замер каждой волны через 7 дней (ставить systemd-таймер → Telegram).
- Причина №1 «за ТОП-100» у дальнего хвоста — НЕ контент, а индексация.

## 4. Единые источники данных + стражи (фундамент)
Цены, даты, производные величины (вычеты) — derived-константы из одного data-файла; build-стражи роняют сборку при любом литерале вне канона (allowlist для легитимных не-канон сумм/дат). Протяжка по страницам: детерминированный скрипт (кавычки→template literal, JSX→{X}), затем скан собранного HTML на утечки `{CONST}`. ГРАБЛИ: client-side `<script>` не видит импортов — там литералы остаются (страж охраняет); multiline-regex по кавычкам рвёт файлы — только line-scoped.

## 5. Инструментальные протоколы
См. «SEO — основные правила» §Инструментальный стек (10.06.2026): Cloud Wordstat (Api-Key+folderId), Arsenkin set→task_id→get (батчи 100, 429-паузы), Mutagen 2-шаговый, Топвизор-форматы (1 фраза/вызов!), Вебмастер recrawl (WEBMASTER_TOKEN). Долгие циклы — только nohup+лог на сервере.

## 6. Чек-лист раскатки на новый сайт
1. Доступы: Топвизор project_id, Вебмастер host+token, Метрика, Wordstat-ключ (общие в /opt/aidacamp-tools/mcp/.env подходят).
2. Шаг 1 (аудит) → стратегия-документ с зонами → дашборд.
3. Калибровка strong по чемпионам сайта.
4. Фронты A→B→C→D волнами по 5–10 страниц, лог изменений обязателен, замеры таймерами.
5. Единые источники фактов сайта (цены/даты/контакты) + стражи — до массовых правок текста.
