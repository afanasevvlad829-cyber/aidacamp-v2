## 2. Почему "детский лагерь" скатился

### История позиций (по snapshot-данным и Вебмастеру)

- **До апреля**: позиция ~11 (пользователь помнит ТОП-11)
- **Середина апреля**: показы упали, позиция болтается 7–17
- **28 апреля**: Вебмастер показывал 5 показов (аномальный выброс, не реальный обвал)
- **May 2**: Arsenkin не нашёл нас в ТОП-30 (точечная проверка)

### Причины нестабильности

1. **Каннибализация от старого Tilda-блога**
   - URL `/tpost/jhxf4cog71-luchshii-detskii-lager-v-podmoskove-otdi` → 301 → `/detskiy-lager-podmoskove/`
   - Яндекс ещё держит в индексе old URL и иногда показывает его, а не главную страницу
   - Это делит "вес" между двумя URL на один запрос

2. **Слабая частота ключа на главной странице**
   - В `index.astro` слово "детский лагерь" появляется ~2-3 раза
   - В ТОП-1 конкурентов — 6-10 вхождений (из LSI-анализа)

3. **Текущий Title главной страницы**
   - "Летний детский IT-лагерь в Подмосковье 2026 — Python, Minecraft | АйДаКемп"
   - Слова "детский лагерь" стоят НЕ в начале Title — снижает вес для этого ключа

4. **Конкурентная среда усилилась к лету**
   - Все лагеря делают SEO-спурт в апреле-мае

## 3. Стратегия: какая страница под какой ключ

### Карта страниц ↔ ключей

```
aidacamp.ru/                      ← ГЛАВНАЯ (универсальный хаб)
├── [1ая цель]  детский лагерь
├── [2ая цель]  летний лагерь
├── [3ая цель]  лагерь в подмосковье
├── [держим]    лагерь для детей
├── [держим]    лагерь для подростков
└── [IT-ниша]   it лагерь, компьютерный лагерь

aidacamp.ru/detskiy-lager-podmoskove/   ← ПОСАДОЧНАЯ (подмосковье)
├── [1ая цель]  детский лагерь в подмосковье
├── [цель]      лагерь для детей в подмосковье
└── [поддержка] лагерь подмосковье 2026

aidacamp.ru/kupit-putevku-v-lager/     ← ПУТЁВКИ (коммерческий)
├── купить путевку в лагерь
└── путевка в детский лагерь

aidacamp.ru/stati/*                     ← БЛОГ (информационные)
├── лагерь без гаджетов для детей
├── it летняя школа / летняя школа it
└── компьютерная зависимость подростки
```

**Принцип:** не создавать дублирующие посадочные под "летний лагерь" или "лагерь для подростков" — они хорошо конвертируют с главной (CTR 30-57%). Там достаточно удержания, не нужна отдельная страница.

## 4. Приоритеты: что делать и в каком порядке

### 🔴 ПРИОРИТЕТ 1: Укрепить "детский лагерь" на главной

**Потенциал:** с pos 10.6 → pos 5 = +~200 кликов/мес при той же конверсии

**Действия:**

#### 4.1 Исправить Title главной страницы
Текущий: `Летний детский IT-лагерь в Подмосковье 2026 — Python, Minecraft | АйДаКемп`

Проблема: "летний детский IT-лагерь" — алгоритм воспринимает это как один кластер. Ключ "детский лагерь" без IT-контекста имеет другой интент.

Предлагаемый вариант:
```
Детский лагерь в Подмосковье 2026 — IT, Python, Minecraft | АйДаКемп
```
- "Детский лагерь" стоит первым — максимальный вес
- "Подмосковье" сразу — важен гео-сигнал
- "IT, Python, Minecraft" — дифференциатор

#### 4.2 Увеличить частоту ключа в тексте главной
Цель: "детский лагерь" + "летний лагерь" встречаются 5-7 раз каждый в тексте `index.astro`
- H1: оставить "IT-лагерь" (бренд), но проверить что "детский" присутствует
- Первый параграф: добавить фразу вида "Ищете **детский лагерь** в Подмосковье на лето?"
- Секция "О лагере": добавить "Наш **летний лагерь** — это..."
- Карточки смен: в описании написать "в нашем **детском лагере**"

#### 4.3 Устранить каннибализацию
```bash
# Отправить старый tpost URL на переиндексацию как "удалённый"
# В Яндекс.Вебмастер → Инструменты → Переобход страниц
# URL: https://aidacamp.ru/tpost/jhxf4cog71-luchshii-detskii-lager-v-podmoskove-otdi
```
Убедиться что `robots.txt` или `noindex` не мешает 301-редиректу.

#### 4.4 Добавить микроразметку LocalBusiness на главную
```json
{
  "@type": "LocalBusiness",
  "name": "Детский IT-лагерь АйДаКемп",
  "description": "Летний детский лагерь в Подмосковье для детей 8-17 лет"
}
```

### 🟡 ПРИОРИТЕТ 2: Починить нулевой CTR (2 700 показов в никуда)

**Потенциал:** +100-200 кликов/мес при CTR хотя бы 5-8%

**Почему нулевой CTR:**
- Ключи вида "лагерь детский" (обратный порядок) — Яндекс показывает нас в **Яндекс.Каталоге** (widget), а не в обычной выдаче. Клики считаются как показы, но на сайт не идут.
- "it летняя школа", "летняя школа it" — likely показывает в блоке «Образование» с телефоном, адресом. Звонки идут мимо аналитики сайта.

**Действия:**
1. Проверить в Яндекс.Вебмастер → Статистика запросов: по каким URL показывается "лагерь детский" — если `/`, то это каталог-трафик, не оптимизировать дальше
2. Для "it летняя школа" — убедиться что в Яндекс.Бизнес прописан телефон и UTM-ссылка (чтобы считать звонки)
3. Snippet-оптимизация description для нулевых ключей:
   - Текущий description главной: проверить содержит ли CTA и цифры
   - Добавить в description: "от X ₽/неделю, смены с июня по август, 100+ отзывов 5.0"

## 5. Что НЕ делать

| Соблазн | Почему не нужно |
|---------|----------------|
| Создать отдельную страницу под "летний лагерь" | CTR с главной уже 15.5%, страница работает |
| Создать страницу под "лагерь для подростков" | CTR 29.7%, pos 3.8 — отлично и так |
| Оптимизировать нулевые CTR-ключи | Это каталог-трафик, не сайтовый |
| Делать вечные внешние ссылки под "детский лагерь" | Сначала исправить контент, потом линки |
| Срочно менять дизайн | SEO-проблема не в дизайне |
