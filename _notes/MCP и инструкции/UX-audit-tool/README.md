# UX-аудит-инструмент

Инструмент для быстрого UX/UI аудита веб-сайта через Anthropic API. Результат — структурированный JSON + красивая HTML-презентация с оценками, приоритетами фиксов и рекомендациями.

**Файлы:**
- `ui-audit-tool.jsx` — React SPA (весь код на 1 файл, запускается из браузера / Claude Artifacts / Vite)
- `example-aidacamp-2026-04-19.html` — пример готового отчёта aidacamp.ru (62/100, 8 critical)

---

## 🎯 Когда использовать

| Ситуация | Действие |
|---|---|
| Перед запуском новой LP / новой кампании | Прогнать аудит → получить чеклист фиксов |
| Высокий bounce на мобилке (наш случай 55% vs 21%) | Аудит выявит UX-проблемы карточек, CTA, типографики |
| После смены дизайна / редизайна | Контроль качества |
| Перед покупкой платного трафика | Чтобы не сливать бюджет на сайт с 14px body-текстом |
| Каждый квартал | Плановая проверка (drift monitoring) |

---

## 🚀 Быстрый запуск (3 способа)

### Способ 1 — в Claude Artifacts
1. Открываешь claude.ai → new chat
2. Вставляешь содержимое `ui-audit-tool.jsx` и просишь «сделай артефакт и запусти»
3. Работает как web-app в Claude

### Способ 2 — локально через Vite
```bash
npm create vite@latest ux-audit -- --template react
cd ux-audit
cp /path/to/ui-audit-tool.jsx src/App.jsx
npm install
npm run dev
```
Открыть http://localhost:5173, ввести URL → «Проверить».

### Способ 3 — через Python / curl (без UI)
Используй только ANTHROPIC_SYSTEM prompt из файла + URL сайта → получи JSON → рендери как HTML (скопировать CSS из example).

Готовый prompt (см. `prompt-template.md`).

## 📊 Что проверяет (5 секций + приоритеты)

| Секция | Что ищет |
|---|---|
| **Контраст и цвет** | WCAG AA 4.5:1, цвета вспомогательного текста, overlay на фото |
| **Типографика** | Размеры шрифтов (16px mobile), line-height 1.4-1.7, иерархия h1/h2/h3 |
| **Мобильная версия** | Tap targets ≥44px, горизонтальный скролл, padding 16px |
| **Лэйаут и иерархия** | F-паттерн, закон Хика, закон Фиттса, whitespace |
| **Психология цвета** | Синий=доверие, зелёный=безопасность, оранжевый=срочность; premium/children контекст |

Плюс **priorityFixes** — отсортированные фиксы с impact × effort.

## 💡 Пример кейса (наш, 2026-04-19)

См. `example-aidacamp-2026-04-19.html`.

**Результат:** 62/100, 8 critical issues.

**Топ-3 находки которые совпали с нашими данными Метрики:**
1. **CTA не full-width** → Метрика: 81% drop-off «нажал кнопку / отправил форму»
2. **Body 14px мобилка** → Метрика: Smartphones bounce 55% vs PC 21%
3. **Нет синего доверия для мам** → проблема с ретеншн активных клиентов

**Эффект фиксов** (план в `_notes/АйДаКемп/Маркетинг/План-mobile-UX-фиксов-2026-04.md`):
- Mobile bounce 55% → 35%
- Drop-off 81% → 60%
- Заявки +2-3×
