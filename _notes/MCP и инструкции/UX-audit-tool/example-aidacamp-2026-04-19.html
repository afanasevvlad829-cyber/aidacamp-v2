Общая оценка дизайна

Сайт функционален и содержит нужную информацию, но не дотягивает до уровня доверия, которого ожидает целевая аудитория — мамы 34–45 лет. Оранжевый акцент создаёт энергию, но не безопасность. Мобильная версия требует приоритетных правок.

Детальный анализ

Контраст и цвет

3 проблемы (2 критических) · 2 ок
[Критично]Вспомогательный текст (#767676 на белом) даёт контраст 4.48:1 — ниже WCAG AA (4.5:1). На мобиле при ярком солнце нечитаем.
→ Фикс: Заменить на #555555 (контраст 7.4:1). Один CSS-токен, правка за 5 минут.
[Критично]Белый текст на оранжевой кнопке (#ec7c00): контраст 2.9:1 — провал по WCAG AA для нормального текста.
→ Фикс: Затемнить кнопку до #c45f00 или сделать текст тёмным #1a1a1a. Либо добавить text-shadow для читаемости.
[Важно]Текст поверх hero-фото без достаточного overlay — контраст нестабилен в зависимости от изображения.
→ Фикс: Добавить постоянный gradient overlay: linear-gradient(rgba(0,0,0,0.45), rgba(0,0,0,0.45)).
✓Оранжевый акцент хорошо контрастирует на светлом фоне секций
✓Тёмный заголовок (#111) на белом фоне — отличный контраст 19:1

Типографика

4 проблемы (2 критических) · 2 ок
[Критично]Body-текст на мобиле — 14px. Для мам 34–45 лет это пограничный размер, особенно при дальтонизме или при чтении в очках.
→ Фикс: Минимум 16px для body на мобиле. Плюс это устранит auto-zoom Safari на полях формы.
[Критично]Line-height у ряда абзацев — 1.4, слишком плотно для длинных описаний смен и FAQ.
→ Фикс: Line-height 1.6–1.7 для всех абзацев длиннее двух строк.
[Важно]Иерархия заголовков нарушена в секции FAQ — h3 визуально тяжелее h2 родительского блока.
→ Фикс: Привести к шкале: h1=36px, h2=28px, h3=22px с консистентными font-weight.
[Совет]Ширина текстовых блоков местами превышает 80 символов на десктопе — читатель устаёт.
→ Фикс: max-width: 65ch для абзацев внутри контентных секций.
✓Inter — разборчивый шрифт для кириллицы, хорошо рендерится на всех платформах
✓Жирные заголовки секций создают чёткую визуальную точку входа

Мобильная версия

4 проблемы (2 критических) · 2 ок
[Критично]Основная CTA-кнопка «Выбрать смену» в hero занимает не всю ширину экрана — tap target неудобен одной рукой.
→ Фикс: width: 100%, min-height: 48px на мобиле. Стандарт Apple HIG и Google Material.
[Критично]Карточки смен требуют горизонтального скролла — часть мам не догадывается свайпать, уходит не увидев все варианты.
→ Фикс: Добавить явный индикатор свайпа (точки или «свайп →») + показывать 1.2 карточки чтобы намекать на продолжение.
[Важно]Телефонные номера в шапке — мелкие иконки без текста на мобиле. Мама не найдёт как позвонить быстро.
→ Фикс: Закреплённая нижняя панель на мобиле с кнопками «Позвонить» и «WhatsApp».
[Совет]Отступы от краёв экрана в ряде секций — 8px вместо рекомендованных 16px.
→ Фикс: padding: 0 16px для всех секций на мобиле.
✓Адаптивная сетка работает корректно, нет горизонтального overflow
✓Изображения используют srcset — загружаются в нужном размере

Лэйаут и иерархия

3 проблемы (1 критическая) · 3 ок
[Критично]На hero-экране мобиле конкурируют два CTA одинакового визуального веса — мама не знает что нажать первым (закон Хика).
→ Фикс: Один первичный CTA (оранжевый, большой) + один текстовый вторичный («Узнать подробнее»).
[Важно]Блок с ценами расположен ниже fold после большого количества контента — конверсионный элемент спрятан.
→ Фикс: Поднять цену («от 48 000 ₽») в hero как anchor — не как основной CTA, но как ориентир.
[Совет]F-паттерн чтения нарушён в секции «О лагере» — важные тезисы размещены справа, а не слева.
→ Фикс: Ключевые буллиты — всегда в левой колонке. Правая — иллюстрации/фото.

✓Sticky header обеспечивает доступ к контактам в любой точке страницы
✓Whitespace между секциями достаточный — страница «дышит»

Психология восприятия

4 проблемы (2 критических) · 3 ок
[Критично]Отсутствует якорный цвет доверия (синий) — для мамы отправляющей ребёнка на 2 недели это ключевой психологический сигнал надёжности.
→ Фикс: Добавить синие акценты (#1a5fa8) в блоки: лицензия, команда, отзывы, безопасность.
[Критично]Социальный proof («1200 детей», «7 лет», «5.0») спрятан — не виден без скролла. Мамы принимают решение в первые 8 секунд.
→ Фикс: Вынести 3 ключевых цифры в hero-блок над fold, крупным шрифтом рядом с заголовком.
[Важно]Фотографии детей малого размера в карточках — мама не может «примерить» лагерь на своего ребёнка.
→ Фикс: Крупные эмоциональные фото детей выше fold. Не архитектура, не компьютеры — лица и эмоции.
[Совет]Нет визуального триггера срочности для мам которые «думают» — заполняемость смен есть, но не акцентирована.
→ Фикс: Progress bar занятости смен + «Осталось X мест» красным рядом с ценой.
