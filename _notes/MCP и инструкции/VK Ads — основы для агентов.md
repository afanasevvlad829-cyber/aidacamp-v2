# VK Ads — основы для агентов

> ⚠️ **Для агентов**: правила работы, которые считаются само-собой разумеющимися. Читать ПЕРЕД вопросами к владельцу.

Проект: **aidacamp.ru** — детский IT-лагерь. Основная ЦА во ВК — родители 30–50 в группах про детский досуг, образование, подмосковные лагеря. Плюс ретаргет с сайта.

## 1. VK Ads (новый кабинет) vs myTarget (старый)

| | VK Ads (ads.vk.com) | myTarget (target.my.com) |
|---|---|---|
| Статус в 2026 | **Актуальный**, все новые функции тут | Постепенно сливается с VK Ads, многие функции уже перенесены |
| Интерфейс | Современный, единый для ВК + Одноклассники + Дзен + Почта Mail + РСМ (рекламная сеть Mail) | Старый, но более «плотный» по настройкам |
| API | VK Ads API (актуальный) | myTarget API (поддержка сокращается) |
| Таргетинги | Синхронизированы с ВК (сегменты сообществ, интересы) | То же + legacy-таргеты |
| Пиксели | **VK Pixel (top-fwz1 / top_mail_ru)** | top_mail_ru (тот же, унаследован) |
| Где у нас реклама | **VK Ads, новый кабинет** | Не используется напрямую |

**Правило**: если встречаешь в интерфейсе/API сущности myTarget — это legacy, не путай с VK Ads. В новом VK Ads кабинете структура и терминология отличаются.

Источник: https://ads.vk.com/help/

## 2. Структура

```
Кабинет (Account)
└── Кампания (Campaign)        ← цель, бюджет, даты, стратегия ставок
    └── Группа объявлений (AdGroup) ← таргетинги, аудитории, плейсменты
        └── Объявление (Ad)    ← креатив, текст, ссылка, UTM
```

Аналогия с Яндекс.Директом: **Кампания → Группа → Объявление** — структура идентична. Зона ответственности тоже похожа:
- **Кампания**: цель (что оптимизируем), бюджет, даты, стратегия.
- **Группа**: таргетинги (гео, демо, интересы, аудитории, ключи), плейсменты, ставки уровня группы.
- **Объявление**: креатив (картинка/видео/карусель), текст, заголовок, кнопка, URL.

⚠️ **Частая путаница**: `campaign_id` ≠ `ad_group_id` ≠ `ad_id`. В API эти ID не взаимозаменяемые. При написании отчётов и скриптов — всегда явно указывать уровень.

| Цель | Что оптимизирует | Когда использовать |
|---|---|---|
| **Сайт: конверсии** | События пикселя (заявка, покупка) | Основная цель у нас — заявки с LP |

| **Просмотры видео** | CPV | Охватные видеокампании |

## 4. Таргетинги во ВК

| Тип | Описание | Полезность для нас |
|---|---|---|
| **Гео** | Страна, город, радиус от точки | Москва + МО + ключевые города-сателлиты |
| **Демография** | Пол, возраст, семейное положение | Женщины 28–50 (мамы), мужчины 32–55 (папы) |
| **Интересы** | Предзаданные Mail.ru категории | «Родители», «Образование детей», «Детский досуг» |
| **Ключевые фразы** | Поисковые запросы в ВК/Mail за N дней | Актуально: «лагерь для детей», «IT-лагерь» |
| **Группы / сообщества** | Подписчики или активные участники конкретных групп | Родительские группы МО, лагеря-конкуренты |
| **Сегменты пикселя (ретаргет)** | Посетители сайта по событиям | Критично: все события пикселя → сегменты |
| **CRM-аудитории (Look-alike)** | Загрузка своей базы (телефоны/email) → LAL | Работает, если база 1000+ |
| **Сегменты «Мой бизнес» / «Аудитории»** | Готовые сегменты Mail.ru Group | По ситуации |

**Look-alike во ВК**: считается на основе поведения. Рекомендуемая база — **1000+ качественных контактов** (реальные клиенты, не лиды).

Источник: https://ads.vk.com/help/articles/targeting

## 5. Форматы объявлений

| Формат | Где показывается | Особенности |
|---|---|---|
| **Универсальная запись (моноформат)** | ВК лента, ОК | Текст + 1 медиа (картинка/видео) |
| **Карусель (карточки)** | ВК лента | 3–10 карточек с картинкой, заголовком, ценой, ссылкой |
| **Клипы / вертикальное видео** | VK Клипы, Stories | Вертикаль 9:16, до 60 сек |
| **Видео в ленте** | ВК, ОК, Дзен | Горизонталь 16:9 или квадрат |
| **Статичный баннер** | РСМ (сайты-партнёры) | Как обычная медийка |

**Правило креативов для родительской аудитории**: реальные дети на фото (с разрешением родителей), не сток; позитив, безопасность, образовательный результат.

## 6. Пиксель и атрибуция

### VK Pixel (он же `top_mail_ru`, он же `vk.com/rtrg`)
- Один код на всех площадках Mail Group: VK Ads, старый myTarget, ВК ретаргет из кабинета сообщества.
- Устанавливается в `<head>` сайта.
- События: `PageView`, `AddToCart`, `InitiateCheckout`, `Purchase`, **и кастомные** (`Lead`, `CompleteRegistration`, etc.).

### Как НЕ сломать
1. **Не оборачивай VK pixel в Partytown / defer / lazy** без тестирования — частая причина, что события не долетают (у нас **реальный инцидент с `ym()` и Partytown**, с VK pixel ровно такая же логика: пиксель должен отрабатывать в основном потоке, до взаимодействия).
2. **Не меняй ID пикселя в процессе обучения** — алгоритм начнёт учиться с нуля.
3. **CSP / Content-Security-Policy** должна разрешать `top-fwz1.mail.ru`, `ad.mail.ru`, `*.vk.com` (проверь на проде).
4. **Тестируй события через VK Ads → «Проверка пикселя»** после каждой правки.

### Связь с Яндекс.Метрикой
VK Pixel и Яндекс.Метрика — **два независимых счётчика**. Синхронизировать их не нужно, и напрямую данные не связываются. Нюансы:
- Обе считают конверсии независимо — цифры будут расходиться на 5–20% (нормально, из-за разных моделей атрибуции и блокировщиков).
- Если хочешь **единую атрибуцию** — смотри в сторону Roistat / Calltouch / собственный серверный трекер.
- **UTM-метки — единый язык** для обоих пикселей. Следи, чтобы UTM с VK объявлений совпадали с правилами твоей UTM-схемы (см. notes проекта).

Источник: https://ads.vk.com/help/articles/pixel

## 7. Минус-слова и минус-площадки в VK Ads

Это **НЕ прямой аналог Яндекс.Директа**. Обстановка:

| | Есть в VK Ads? | Как работает |
|---|---|---|
| **Минус-слова** (для кампаний с ключами) | Да, есть | Задаются при ключевом таргетинге. Аналогично Директу: исключают запросы из поисковых фраз пользователей |
| **Минус-площадки / исключённые плейсменты** | **Частично**: можно отключать **плейсменты** (Дзен, ОК, РСМ, VK Клипы и т.д.) на уровне кампании. Детального exclude-списка доменов РСМ как в Директе **нет** (не нашёл в официальной доке, уточнить у владельца перед тем, как строить стратегию вокруг этого). |
| **Исключение аудиторий / сегментов** | Да | В группе можно указать `exclude_segments` — сегменты пикселя, которым НЕ показывать (например, исключить уже купивших) |

**Правило**: если в VK Ads кампания «Сайт: конверсии» без минус-слов — это нормально, если там не используется ключевой таргетинг. Минус-слова имеют смысл только при таргетинге **по ключам**.

Источник (неполный, см. пометку выше): https://ads.vk.com/help/articles/targeting_keywords

## 8. Стратегии ставок и оптимизация

| Стратегия | Описание | Когда |
|---|---|---|
| **Минимальная цена (MINIMUM_CPC / Minimum price)** | Алгоритм старается купить показы/клики максимально дёшево в рамках бюджета | Старт, когда нет данных |
| **Предельная цена (Max bid)** | Ты задаёшь потолок CPC/CPM, система не перейдёт его | Когда знаешь свой unit-экономический потолок |
| **Оптимизация по конверсиям (MAX_CONVERSIONS)** | Максимум конверсий, автоматические ставки | Когда есть 10+ конверсий/нед и обученный пиксель |
| **Целевая цена за конверсию (Target CPA)** | Алгоритм держит CPA в районе указанного | Когда пиксель стабильно стреляет, CPA предсказуем |

**Правила обучения**:
- Кампании на конверсии учатся **7–14 дней**, не трогай в этот период.
- Минимум **10 конверсий в неделю** на кампанию — иначе обучение не сойдётся.
- Если конверсий меньше — старт через трафик/клики, накопление данных, потом переход на конверсии.

### Бюджет
- Можно задавать **дневной** или **общий на всю кампанию**.
- **Минимальный дневной бюджет** обычно в районе 100–300 ₽ в зависимости от кампании (проверять актуальные лимиты в интерфейсе — меняются).
- В процессе обучения **не меняй бюджет больше чем на 20–30% за раз**, иначе алгоритм ресетится.

### Даты
- Если задал `date_end`, в последние сутки часто идёт «выгорание» бюджета — нормально.
- Не ставь кампанию «без даты окончания» на долгий срок — потеряешь контроль за открутом.

## 9. Частые ошибки и инциденты

### 9.1. VK pixel с deferred-загрузкой → атрибуция поехала
Классический кейс (у нас на проекте есть ровно такой же риск с Метрикой + Partytown). Если VK pixel грузится после `load` или через Partytown — события частично теряются, система учится на неполных данных, CPA завышается.
**Урок**: пиксель — синхронный, в `<head>`, без lazy/defer.

### 9.2. Путаница `campaign_id` vs `ad_group_id`
В API и отчётах часто встречается путь `campaigns/{id}/groups` и `groups/{id}/ads`. **Агенты часто передают ID кампании туда, где ждут ID группы** — получают 404 или пустой ответ.
**Урок**: всегда называй переменные явно (`vk_campaign_id`, `vk_ad_group_id`, `vk_ad_id`), не используй безликое `id`.

### 9.3. Исключения аудиторий забыли
Кампания на привлечение льёт на тех, кто **уже купил** — деньги в трубу.
**Урок**: в любой performance-кампании — exclude-сегмент «уже совершили целевое действие» (по пикселю).

### 9.4. CSP на сайте блокирует пиксель
Добавили Content-Security-Policy на сайт, забыли прописать домены Mail.ru → пиксель молчит → конверсии в ноль.
**Урок**: при правке CSP — сначала добавить `top-fwz1.mail.ru`, `ad.mail.ru`, `vk.com`, `*.vk-cdn.net` в `img-src`, `script-src`, `connect-src`.

### 9.5. Lookalike на слишком маленькой базе
Загрузили 200 контактов → LAL работает плохо, сегмент «широкий» до уровня «все родители».
**Урок**: LAL осмыслен при 1000+ качественных контактов.

## 10. Специфика aidacamp.ru в VK Ads

- **Основная цель**: заявка на сайте (`Lead` event пикселя).
- **Доп. форматы**: лид-формы ВК (хорошо идут на mobile), ретаргет с сайта, LAL от базы уже купивших.
- **Креативы**: реальные дети в деятельности (программирование, робототехника), спокойные родители-отзывы.
- **Гео**: Москва + МО (радиусы от станций метро + транспортных хабов), опционально Тверь/Калуга/Владимир.
- **Сообщества-таргеты**: родительские группы МО, группы детских лагерей (конкуренты), образовательные сообщества.
- **Сезонность**: старт кампаний за 2–4 мес до смены, пик за 3–6 нед до даты.
