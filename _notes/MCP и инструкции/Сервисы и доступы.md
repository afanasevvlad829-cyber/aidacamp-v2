## Cron-задачи

```
0 6-21 * * *   /opt/etl/run-etl.sh              # ETL каждый час 6:00–21:00
5 6-21 * * *   sudo -u postgres python3 vk-sync  # VK синхронизация
```

## База данных (PostgreSQL)

БД: `aidacamp`, пользователь: `postgres` (peer auth)

| Таблица | Данные |
|---|---|
| `direct_campaign_stats` | Директ: клики, показы, CTR, расход, конверсии |
| `direct_placements` | Площадки РСЯ |
| `metrika_traffic` | Визиты по источникам |
| `metrika_goals` | Конверсии по целям |
| `metrika_utm` | UTM-метки |
| `metrika_demographics` | Пол + возраст |
| `metrika_geo` | География (город, регион) |
| `metrika_devices` | Устройства + ОС |
| `metrika_entry_pages` | Страницы входа |
| `metrika_search_phrases` | Поисковые фразы |
| `vk_ads_stats` | VK реклама |
| `clarity_daily` | Clarity: сессии, dead/rage clicks, scroll depth |
| `clarity_pages` | Clarity по URL |
