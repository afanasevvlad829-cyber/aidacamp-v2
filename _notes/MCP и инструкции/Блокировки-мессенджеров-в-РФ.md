## 💡 Проверенные решения для обхода

### 0. ⭐ Green-API для WhatsApp (рекомендуется)

**https://green-api.com** — российский сервис-посредник для WhatsApp. У них свои серверы (вне блокировки), наш сервер стучится к ним обычным REST API.

**Плюсы:**
- Работает с РФ-IP без прокси
- Нет риска бана основного аккаунта (Green-API этим занимается)
- Webhook + REST — просто в интеграции
- Принимает/отправляет всё (текст, файлы, голос)

**Минусы:**
- Платно (~2 000 ₽/мес за 1 instance)
- История через API — только последние ~100 сообщений на чат (но новые идут в реальном времени через webhook)

**Использовать, когда:** нужен WhatsApp в продакшене, нет времени городить WireGuard/VPS.

**У нас:** instance есть (2026-04-19), подключение настраиваем.

### 1. TOR + proxychains4 (бесплатно, установлено на сервере)

**Установлено:** `/usr/bin/tor` (systemd active) + `/usr/bin/proxychains4`
**Конфиг:** `/etc/proxychains4.conf` настроен на `socks5 127.0.0.1:9050`

**Простой трафик:**
```bash
proxychains4 -q curl -s https://ifconfig.me
# → 192.42.116.52 (TOR exit в Европе)

proxychains4 -q curl -sI https://web.whatsapp.com
# → HTTP/2 200 ✅
```

**Ограничения TOR:**
- Медленный (1–5 Мбит/с)
- WebSocket часто требует *SOCKS5-aware* dialer в приложении (не ловится через LD_PRELOAD / proxychains при использовании CGO / DNS через libresolv)
- Exit IP меняется — WhatsApp может ругаться на «подозрительный вход»
- Нестабильность — линки падают, нужен auto-reconnect

### 2. Wireguard/OpenVPN → дешёвый VPS вне РФ ($3–5/мес)

Для **production-stable** решения:
- Hetzner Finland (€3.49/мес), Contabo Germany ($4/мес), Netcup Nuremberg (€3/мес) — оплата без российских карт
- Поднимаем WG endpoint, маршрутизируем только выделенный сервис через туннель
- Весь остальной трафик (сайт aidacamp.ru, SSH, API) идёт напрямую — прод не страдает

**Готовые конфиги:** пока нет, пишем по запросу.

### 3. SOCKS5-aware приложение

Если приложение поддерживает SOCKS5 напрямую — это лучший вариант (без обёрток):
- **whatsmeow** (Go) — `client.SetProxy(url.Parse("socks5://127.0.0.1:9050"))`
- **Baileys** (Node.js) — `socksDispatcher` в конфиг
- **requests** (Python) — `proxies={'https': 'socks5h://127.0.0.1:9050'}`

Это единственный рабочий путь для whatsmeow — proxychains4 НЕ работает с ним из-за CGO/DNS.

## 🎯 Практические рекомендации

### Делать с сервера (через IP РФ):
- ✅ Telegram (бот, user API, экспорты)
- ✅ Яндекс (Direct, Метрика, Вебмастер, Wordstat)
- ✅ VK (Ads, API)
- ✅ Google Drive (медленнее, но работает)
- ✅ AlfaCRM (`codim.s20.online`)
- ✅ SSH/git/apt

### НЕ делать с сервера без SOCKS5/VPN:
- ❌ WhatsApp (любая работа с Meta серверами)
- ❌ Meta Business API (Facebook Graph)
- ❌ Instagram API / scrape
- ❌ Threads

### Что делать, если нужен WA/Meta:
1. **Первый выбор:** поднять маленький VPS вне РФ и использовать его как exit для wireguard (самый стабильный)
2. **Быстрый MVP:** модифицировать клиент, чтобы он сам ходил через SOCKS5 (TOR) — работает, но медленно и нестабильно
3. **Крайний случай:** запускать WA-клиент на домашней машине (Mac/Linux, не в РФ-VPN) — но тогда она должна быть всегда онлайн

В Go-коде `/opt/wa/main.go` добавить:

```go
import (
    "net/url"
    "go.mau.fi/whatsmeow/proxy"
)

// После NewClient:
proxyURL, _ := url.Parse("socks5://127.0.0.1:9050")
client.SetProxy(proxyURL)
```

Но SOCKS5 через TOR для постоянного linked device — **плохая идея** (IP меняется → WhatsApp помечает как подозрительное). **Лучше WireGuard-туннель на VPS**.

## 📋 История блокировок (для памяти)

- **2018 апр – 2020 июн** — Telegram заблокирован в РФ. С 2020 разблокирован.
- **2022 мар** — Instagram, Facebook заблокированы как «экстремистские». Meta заблокирована целиком.
- **2022 окт** — WhatsApp технически доступен, но Meta-домены режутся частично.
- **2024 авг** — усиление блокировки WhatsApp (часть серверов Meta недоступны).
- **2025–2026** — WhatsApp стабильно **не ходит** с РФ-IP в большинстве провайдеров (web.whatsapp.com, graph.facebook.com — timeout). Мобильные клиенты продолжают работать через Meta-маршрутизацию с fallback — но скрейпинг не проходит.

## ✅ Полезные команды для диагностики

```bash
# exit IP обычно
curl -s https://ifconfig.me

# exit IP через TOR
curl -s --socks5-hostname 127.0.0.1:9050 https://ifconfig.me

# проверка что сервис жив
systemctl is-active tor

# рестарт TOR для новой сессии/цепочки
systemctl restart tor

# тест доступности WA
curl -s --max-time 10 -I https://web.whatsapp.com
# ожидаемо: timeout

# тест через TOR
proxychains4 -q curl -s --max-time 15 -I https://web.whatsapp.com
# ожидаемо: HTTP/2 200
```
