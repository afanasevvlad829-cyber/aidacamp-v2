## Сервер 2 — server1 (внутренний dev / резервный)

*Зафиксировано: 2026-05-25*

### Назначение
Внутренний сервер для разработки и как резервный по ресурсам. **Только LAN** (наружу не смотрит). Firewall/fail2ban намеренно **не ставим** (внутренний контур).

### Сеть и доступ
- **Имя хоста:** `server1`
- **IP (LAN):** `192.168.1.147` (интерфейс `enp2s0`, кабель, DHCP)
- **Пользователь:** `aida` (пароль `aida` — слабый, для LAN; sudo — по паролю)
- **SSH-доступ с Mac (ключ уже прописан):**
  ```bash
  ssh -i ~/.ssh/id_ed25519 aida@192.168.1.147
  ```
- Вход по паролю в SSH включён (не отключали).

### ОС
- **Ubuntu 24.04.4 LTS Desktop**, ядро 6.17 (HWE).
- Установлена с USB вручную (autoinstall на Desktop-установщике падал — ставили обычным мастером).

### Железо
- **CPU:** Intel **Core i7-3770** (Ivy Bridge, 2012) — 4 ядра / 8 потоков, 3.4–3.9 ГГц.
- **RAM:** 7.6 ГБ (swap не настроен).
- **Диски:**
  | Устр-во | Модель | Тип | Объём | Назначение | Монтирование |
  |---|---|---|---|---|---|
  | `sda` | Kingston SV300S37A120G | **SSD** (SATA) | 120 ГБ | Система (`/`, ext4) | `/` (свободно ~94 ГБ) |
  | `sdb` | Hitachi HDS721050CLA360 | **HDD** 7200 (SATA) | 500 ГБ | **Бэкапы** | `/mnt/backup` (ext4, метка `backup`, ~453 ГБ своб.) |

### Backup-диск
- `/mnt/backup` — 500 ГБ HDD, ext4, владелец `aida` (пишется без sudo).
- Авто-монтирование в `/etc/fstab` с `nofail` (UUID `40f93896-47f6-438c-8fa6-db554d2b0af6`). Переживает переустановку системы.

### Производительность (vs prod)
- Однопоточный бенч: server1 ~4.93 с против prod ~2.67 с → **prod быстрее на ядро ~1.85×** (современный EPYC vs i7 2012).
- Суммарно CPU: server1 **~2.2×** мощнее (8 потоков против 2), RAM в ~1.6× больше и не свопит, диска кратно больше.
- **Вывод:** как dev/резерв — по «грубой силе» ~вдвое мощнее прода, просторнее по диску; однопоточный пик ниже.

### Заметки
- Второй диск раньше содержал старую пустую установку Ubuntu (личных данных не было) — затёрт под бэкапы.
- Установщики/конфиги автоустановки лежат локально на Mac: `~/ubuntu-autoinstall/` (ISO, `user-data`, `meta-data`).
