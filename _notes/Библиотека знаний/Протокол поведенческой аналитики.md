## Блок 2 — Кросс-анализ: устройство × источник × качество

### 2.1. Вовлечённость по сегментам (базовый срез)

```sql
WITH clean AS (
  SELECT * FROM metrika_visits_raw
  WHERE NOT (device='desktop' AND os='linux' AND visit_duration=0)
    AND visit_duration >= 5
)
SELECT
  device,
  traffic_source,
  COUNT(*) AS visits,
  ROUND(AVG(visit_duration)) AS avg_sec,
  COUNT(*) FILTER (WHERE visit_duration > 120) AS engaged_2min,
  ROUND(100.0 * COUNT(*) FILTER (WHERE visit_duration > 120) / COUNT(*), 1) AS pct_engaged,
  COUNT(*) FILTER (WHERE goals_id::text LIKE '%541048270%') AS age_select,
  COUNT(*) FILTER (WHERE goals_id::text LIKE '%545216463%') AS choose_shift,
  ROUND(100.0 * COUNT(*) FILTER (WHERE goals_id::text LIKE '%541048270%') / COUNT(*), 1) AS cvr_age_select
FROM clean
GROUP BY device, traffic_source
ORDER BY visits DESC;
```

### 2.2. iOS vs Android — конверсионная разница

```sql
WITH clean AS (
```

## Блок 6 — Поиск зависимостей (алгоритмический)

### 6.1. Матрица корреляций (Python / scipy)

Запускать локально или через ssh на сервере:

```python
import pandas as pd
import psycopg2
from scipy.stats import chi2_contingency, cramers_v
import numpy as np

# Подключение
conn = psycopg2.connect("host=aidacamp dbname=aidacamp user=...")

df = pd.read_sql("""
  SELECT device, traffic_source, os,
    CASE WHEN os LIKE 'ios%%' THEN 'ios' ELSE 'android' END as platform,
    CASE WHEN visit_duration >= 120 THEN 1 ELSE 0 END as engaged,
    CASE WHEN goals_id LIKE '%%541048270%%' THEN 1 ELSE 0 END as converted,
    visit_duration, page_views
  FROM metrika_visits_raw
  WHERE NOT (device='desktop' AND os='linux' AND visit_duration=0)
    AND visit_duration >= 5
""", conn)

# Cramér's V между всеми категориальными переменными
dims = ['device', 'traffic_source', 'platform']
target = 'converted'

for dim in dims:
    ct = pd.crosstab(df[dim], df[target])
    chi2, p, dof, _ = chi2_contingency(ct)
    n = ct.sum().sum()
    v = np.sqrt(chi2 / (n * (min(ct.shape) - 1)))
    print(f"{dim:20s} → V={v:.3f}  p={p:.4f}  ({'значимо' if p < 0.05 else 'не значимо'})")
```

**Cramér's V:** 0 = нет связи, 1 = полная связь. V > 0.15 → стоит исследовать.

### 6.2. Дерево решений — что предсказывает конверсию

```python
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.preprocessing import LabelEncoder

features = ['device', 'traffic_source', 'platform']
le = {col: LabelEncoder().fit(df[col]) for col in features}
X = pd.DataFrame({col: le[col].transform(df[col]) for col in features})
y = df['converted']

clf = DecisionTreeClassifier(max_depth=4, min_samples_leaf=30, random_state=42)
clf.fit(X, y)
print(export_text(clf, feature_names=features))

# Feature importance
for feat, imp in sorted(zip(features, clf.feature_importances_), key=lambda x: -x[1]):
    print(f"  {feat}: {imp:.3f}")
```

**Результат:** какие признаки сильнее всего предсказывают конверсию, и в каком порядке (правила типа «если ad + ios → конверсия 8%, иначе 2%»).

### 6.3. Mutual Information (нелинейные зависимости)

```python
from sklearn.feature_selection import mutual_info_classif

mi = mutual_info_classif(X, y, discrete_features=True, random_state=42)
for feat, score in sorted(zip(features, mi), key=lambda x: -x[1]):
    print(f"  {feat}: MI={score:.4f}")
```

## Блок 7 — Clarity × Metrika: кросс-источниковый анализ

### 7.1. Страницы с аномалиями

```sql
SELECT
  c.url,
  c.sessions,
  c.scroll_depth_pct,
  c.quickbacks,
  ROUND(100.0 * c.quickbacks / NULLIF(c.sessions, 0)) AS quickback_pct,
  c.dead_clicks,
  c.avg_duration_sec,
  -- Флаги проблем
  CASE WHEN c.scroll_depth_pct < 30 AND c.avg_duration_sec > 120 THEN '⚠ Застряли сверху'
       WHEN ROUND(100.0 * c.quickbacks / NULLIF(c.sessions, 0)) > 50 THEN '🔴 Высокий quickback'
       WHEN c.dead_clicks > 20 THEN '🔴 Мёртвые клики'
       ELSE 'ОК' END AS flag
FROM clarity_pages c
WHERE c.sessions >= 5
ORDER BY c.sessions DESC;
```

### 7.2. Страницы-ловушки (высокое время + низкий scroll + нет конверсий)

```sql
-- Паттерн: пользователь застрял на верхней части страницы надолго
-- Причина: нет CTA рядом с тем, на чём они фокусируются
SELECT url, sessions, scroll_depth_pct, avg_duration_sec,
  dead_clicks,
  CASE WHEN dead_clicks > 10 THEN 'Добавить кликабельность' ELSE '' END AS recommendation
FROM clarity_pages
WHERE scroll_depth_pct < 35
  AND avg_duration_sec > 150
  AND sessions >= 4
ORDER BY avg_duration_sec DESC;
```

## Блок 8 — Direct × Metrika: окупаемость по сегментам

### 8.1. Стоимость engaged-визита по кампании

```sql
-- Соединяем расход Директа с качеством трафика
SELECT
  d.campaign_id,
  d.campaign_name,
  d.cost,
  d.clicks,
  m.engaged_visits,
  ROUND(d.cost / NULLIF(m.engaged_visits, 0), 0) AS cost_per_engaged
FROM direct_campaign_stats d
LEFT JOIN (
  SELECT utm_campaign,
    COUNT(*) FILTER (WHERE visit_duration > 120) AS engaged_visits
  FROM metrika_visits_raw
  WHERE traffic_source = 'ad'
  GROUP BY utm_campaign
) m ON d.campaign_id::text = m.utm_campaign
WHERE d.cost > 0
ORDER BY cost_per_engaged;
```
