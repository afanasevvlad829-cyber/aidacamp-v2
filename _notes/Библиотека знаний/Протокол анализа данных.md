# Протокол глубокого анализа данных — АйДаКемп

> Создан 30.04.2026. Применяется к любому срезу данных: Метрика, Clarity, Директ, VK.
> Цель — не поверхностный отчёт, а системный разбор по всем измерениям и их пересечениям.

---

## Принцип: три уровня глубины

```
Уровень 1 — ЧТО происходит      (цифры, факты)
Уровень 2 — ПОЧЕМУ происходит   (причины, паттерны)
Уровень 3 — ЧТО ДЕЛАТЬ          (конкретные действия с приоритетом)
```

Поверхностный анализ останавливается на уровне 1. Протокол требует всех трёх.

## Блок А — Трафик и источники

### А1. Объём и структура
- Общее количество визитов за период
- Разбивка по источникам: organic / ad / referral / direct / social / saved
- Доля каждого источника, динамика vs предыдущий период

### А2. Качество по каждому источнику
Для каждого источника отдельно:
| Метрика | Зачем |
|---|---|
| Отказы (bounce) | Соответствие аудитории |
| Среднее время на сайте | Реальный интерес |
| Глубина / страницы | Вовлечённость |
| Визиты 2+ минуты | Горячая аудитория |
| Достижение micro-goal | Конверсия в интерес |
| Достижение macro-goal | Конверсия в действие |

### А3. Кросс-анализ: источник × устройство
- Какой источник лучше работает на mobile vs desktop
- Есть ли источники с критично плохим mobile (→ посадочная не адаптирована?)

### А4. Кросс-анализ: источник × время суток / день недели
- Когда приходит качественный трафик
- Пики отказов по времени (→ корректировки ставок)

## Блок Б — Поведение на сайте

### Б1. Скролл-воронка
```
Пришли → 25% → 50% → 75% → 90%
```
- Абсолютные числа и % на каждом шаге
- Наибольший drop-off — где именно
- Сравнение по источникам: organic vs ad vs referral

### Б2. Взаимодействия с элементами
Для каждого отслеживаемого элемента:
- Сколько людей дошли до элемента (scroll)
- Сколько кликнули / открыли
- CTR элемента = клики / дошедшие
- Время от входа до клика (→ где элемент на странице)

### Б3. Пути между элементами
- Какая последовательность действий ведёт к конверсии
- Есть ли "петли" (возвращается к одному блоку несколько раз → сомневается)
- Самые частые пути тех кто НЕ сконвертировался

### Б4. Сессии Clarity — качественный анализ
Смотреть записи по сегментам:
1. **Нажали "Выбрать смену" но ушли** — что произошло после клика
2. **Провели 2+ минуты** — что читали, где остановились
3. **Rage clicks** — куда тыкают без реакции
4. **Dead clicks** — что кажется кликабельным но не является
5. **Быстрые уходы (< 15 сек)** — что видят первым и почему уходят
6. **Мобильные vs десктоп** — разный ли паттерн поведения

## Блок В — Аудиторные сегменты

### В1. Устройства
- mobile / desktop / tablet — объём, качество, конверсия
- Размеры экранов на mobile (→ видны ли CTA на маленьких экранах)
- Разница в скорости загрузки по устройствам

### В2. Новые vs возвращающиеся
- Доля возвращающихся
- Конверсия новых vs возвращающихся
- Сколько визитов в среднем до конверсии (→ длина цикла принятия решения)

### В3. Время суток и день недели
- Распределение трафика по часам
- Конверсия по времени суток (утро / день / вечер)
- Конверсия по дням недели
- → Нужны ли временные корректировки в Директе

### В4. География (для МО-кампаний)
- Москва vs МО — объём, качество, конверсия
- Красногорск / Королёв (таргет Директа) — есть ли вообще трафик
- Аномальные регионы (→ проверить таргетинг)

### В5. Новые сегменты (из Clarity)
- Пользователи с высокой вовлечённостью (scroll 75%+, время 2+ мин)
- Пользователи с Intent-сигналами (открыли смены, нажали возраст)
- → Экспортировать в аудитории Метрики → ретаргет

## Блок Г — Рекламные кампании

### Г1. Эффективность по кампаниям
Для каждой кампании:
- Показы, клики, CTR, расход, CPC
- Конверсии (micro + macro), CPA
- Динамика по дням (нет ли деградации)

### Г2. Кросс-анализ: кампания × качество трафика
- Какая кампания даёт лучший scroll depth
- Какая кампания даёт больше "горячих" (2+ мин, открыл смены)
- CPA не по заявкам, а по micro-целям

### Г3. Площадки РСЯ
- Топ площадок по расходу — качество трафика с каждой
- Bounce rate по площадкам (порог 65%)
- CPC аномалии (< 8₽ = DSP мусор)
- Яндексовые площадки (погода, игры) — отдельная оценка

### Г4. Поисковые запросы
- Запросы с высоким bounce (> 75%) и 0 конверсий → минус-слова
- Запросы с нерелевантной тематикой (спорт, другой регион, другой тип)
- Запросы с хорошей конверсией → поднять ставки / добавить точные вхождения

### Г5. Ставки и аукцион (API Директа)
- Текущие ставки vs требуемые для P11/P14
- Какие ключи не попадают в аукцион
- Средняя позиция показа по группам

## Блок Д — Воронка конверсий (сквозная)

### Д1. Общая воронка (от клика до лида)
```
Показ объявления
    ↓ CTR
Клик / визит
    ↓ (100% - bounce)
Вовлечённый визит
    ↓ scroll 25%+
Прочитал начало
    ↓ scroll 75%+
Прочитал основное
    ↓
Открыл инфо о смене / Выбор возраста
    ↓
Нажал "Выбрать смену"
    ↓
[Бот / Форма / Контакт]
    ↓
Лид в CRM
    ↓
Продажа
```

Для каждого перехода:
- Абсолютные числа
- % конверсии шага
- Главная причина drop-off

### Д2. Micro-цели как прокси лидов
Пока форма не работает — строим суррогатную воронку:
- `age_select` = квалифицированный интерес (67/2774 = 2.4% от рекламы)
- `opened_shift_info` = продуктовый интерес (68/2774 = 2.5%)
- `choose_shift_btn` = намерение (28/2774 = 1.0%)
- Каждый следующий шаг ценнее — ориентир для оптимизации ставок

### Д3. Мультисессионный анализ
- Сколько визитов в среднем у тех кто конвертировался
- Интервал между визитами (день 1 → день 3-7 по портрету)
- Какой источник — последний перед конверсией
- Какой источник — первый (ассоциированные конверсии)

## Блок Е — Аномалии и красные флаги

Всегда проверять:
- [ ] Direct-трафик с bounce > 90% — боты или внутренние проверки?
- [ ] Конверсии с cost = 0₽ — мягкая цель в PAY_FOR_CONVERSION?
- [ ] Резкий рост/падение трафика без изменений в кампаниях → внешняя причина
- [ ] CPC ниже 8₽ в РСЯ → DSP-мусор
- [ ] Площадки с 100% bounce и 3+ кликами → блокировать
- [ ] Регионы вне таргетинга с расходом → проверить гео-настройки
- [ ] ETL не обновлялся > 1 дня → проверить токены API

## Порядок проведения анализа

1. **Сначала аномалии** (Блок Е) — чтобы не строить выводы на грязных данных
2. **Трафик и источники** (Блок А) — понять что вообще приходит
3. **Поведение** (Блок Б) — где и почему теряем
4. **Воронка** (Блок Д) — сквозная картина
5. **Сегменты** (Блок В) — кто лучше конвертируется
6. **Реклама** (Блок Г) — что оптимизировать
7. **Выводы по трём уровням** — ЧТО / ПОЧЕМУ / ЧТО ДЕЛАТЬ
