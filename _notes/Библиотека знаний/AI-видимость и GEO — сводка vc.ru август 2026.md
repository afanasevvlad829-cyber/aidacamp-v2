## Внедрить: мониторинг AI-видимости (бесплатно, три вебмастера)

Источник: [Шутова — «Как бесплатно отслеживать AI-видимость»](https://vc.ru/seo/3059451).
Проверить/включить для всех 5 сайтов:

- **Яндекс.Вебмастер → «Видимость сайта в Алисе AI»** (раздел появился 07.04.2026):
  доля запросов, где сайт в источниках нейроответа + выгрузка XLS конкретных фраз.
- **Bing Webmaster Tools → «AI Performance»**: цитирования в Copilot, Citation Share
  (доля среди всех источников ответа), **Grounding Queries — внутренние поисковые фразы ИИ,
  готовые чистые LSI для оптимизации**. Bing критичен: его индекс кормит ChatGPT.
- **GSC → Эффективность → «Генеративный ИИ»** (бета): AI Impressions. ⚠️ В общем отчёте
  Google ставит позицию 1 всем ссылкам из ИИ-ответов — искажает среднюю позицию.
- Метрика: настроить сегмент/отчёт переходов из ИИ-систем.

## Внедрить: собственный замер Share of Voice в ИИ-ответах

Источник: два замера Никиты Семёнова — [160 вопросов про ремонт](https://vc.ru/seo/3089772)
и [Greek Legend, 109 запросов](https://vc.ru/seo/3103290).

- **Методика**: 100–150 запросов ниши БЕЗ бренда → API ChatGPT (web_search) + Perplexity
  (sonar) → Share of Voice = доля запросов, где домен попал в источники. 218 запросов ≈ 490₽.
- **Ключевые факты** (устойчивы на двух нишах):
  - ChatGPT/Perplexity/Алиса пересекаются по источникам на **1,6–2,7%** — три разных
    интернета; видимость в одном движке ничего не говорит об остальных. Мерить минимум в трёх.
  - **Упоминание бренда держится на ссылке, не на памяти модели**: без своей страницы в
    источниках бренд назван 2 раза из 49. Попадание в источники — «аренда, не депозит».
  - ChatGPT на русские бытовые вопросы до 31% ответов отвечает без единого русского
    источника (epa.gov и т.п.).
  - **Алиса опирается на dzen.ru в 28% ответов** и сервисы Яндекса в 25%. 🤔 Гипотеза для
    владельца: Дзен закрыт нами 14.08 по доходимости, но как донор цитируемости в Алисе
    может заслуживать minimal-effort возврата.

## PR-стратегия под GEO (влияет на текущие питчи!)

Источник: [замер Greek Legend](https://vc.ru/seo/3103290).

- Публикации в **отраслевых изданиях с брендом в заголовке** → бренд назван в 100%
  цитирований ИИ. Федеральные СМИ с экспертизой в тексте → 25–37%: ИИ берёт объяснение,
  выбрасывая имя эксперта.
- **Правило для питчей** (в т.ч. «экранное время»): приоритет — отраслевые/тематические
  издания и заголовок с названием бренда; «экспертная колонка в федеральном» — для людей,
  не для ИИ-видимости.

## В конвейер seo-keyword-grinder

- **FAQ-карточка под GEO** ([Формула клика](https://vc.ru/seo/3094499)): вопрос языком
  пользователя → краткий ответ 1–2 предложения (кандидат в AI-ответ) → развёрнутый →
  исключения/условия отдельным блоком. FAQ по сценариям («если...»), а не по темам.
- **Кластеры по сценариям клиента** ([SEO для стоматологии](https://vc.ru/seo/3076651)):
  «хочу понять» / «уже выбираю» / «конкретная проблема» / «выбираю кому доверить».
  Последний — про людей: страницы педагогов/вожатых с именами = «страницы врачей».
- **Сверка структуры с лидерами** ([Диджитал-картель](https://vc.ru/seo/3094680)):
  у лидера 15–20 URL кормят 80–90% трафика — выгрузить видимость конкурентов (keys.so),
  проверить свои «жирные хабы» прежде чем плодить микространицы. Главный запрос страницы
  сверять по частотности (их пример: «камера» vs «видеорегистратор» — ×10).
- **Гео-лендинги** ([кейс «112 страниц врач+район», конверсия 20%](https://vc.ru/seo/3102366)):
  страница создаётся только при (а) реальном спросе, (б) реальном предложении,
  (в) самостоятельном контенте; интент разведён с общей страницей — иначе каннибализация.
- **Брендовый трафик как метрика E-E-A-T** ([Мозговая](https://vc.ru/seo/3071948)):
  мониторить брендовые запросы в Wordstat/Вебмастере; раз в квартал SERM-проверка в
  инкогнито: «бренд + отзывы», «бренд + развод» ([SERM](https://vc.ru/seo/3069902)).

## Чего НЕ делать (подтверждено независимыми источниками)

- **Фейковая свежесть** — обновление дат без нового контента: [израильский кейс](https://vc.ru/seo/3078353)
  словил просадку и публично отказался от практики.
- **AI-клоакинг / контент только для ботов** — Perplexity банит и снижает trust score
  ([кейс TIME + Mobian](https://vc.ru/seo/3097344)). Правило content parity; наша политика
  «один массив → и UI, и JSON-LD» ему соответствует.
- **Key Collector** — прямой парсинг Вордстата мёртв с 03.2022, признано самими
  разработчиками; в гайдах до сих пор советуют ([разбор трёх способов сбора ядра](https://vc.ru/seo/3100273)).
  Вывод оттуда же: «ядро — это не список фраз, а решения по каждой фразе».
- **llms.txt** — третье независимое подтверждение бесполезности (Петров, [Sirak](https://vc.ru/seo/3093288), тест Ahrefs: 97% файлов без единого запроса).
- **ИИ-аудиторам не верить на слово** — [разбор Петрова](https://vc.ru/seo/3083213):
  чек-лист-аудиты (включая Claude SEO, которым пользуемся и мы) помечают некритичное
  критичным (нет llms.txt, нет sitemap) и пропускают реальное: X-Robots-Tag,
  canonical на 404-страницу, канонизацию www/без-www. Выводы авто-аудита — фильтровать головой.
- **Редизайн без SEO-миграции** — [кейс логистики](https://vc.ru/seo/3089279): трафик ×7-8
  снесён переделкой сайта без сохранения структуры посадочных. У нас правило есть — вот подтверждение.
