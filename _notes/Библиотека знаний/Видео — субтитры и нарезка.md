## Пайплайн нарезки видео из исходника

### Исходные данные
- Один длинный MP4-файл (`darya_qa_final.mp4`) с несколькими сегментами
- Тайм-коды сегментов задаются вручную (STARTS/ENDS в секундах)

### Шаги

**1. Генерация карточек (Python + Pillow)**
```python
from PIL import Image, ImageDraw, ImageFont
img = Image.new("RGB", (1280, 720), (27, 25, 41))  # #1b1929
# Шрифт: /Library/Fonts/Arial Unicode.ttf
# Размер заголовка: 72px, вопроса: 34px
# Центрирование по горизонтали, вручную по вертикали (y=260 / y=390)
img.save(f"card_{fn}.png")
```

**2. Карточка → MP4 с тишиной (4 секунды)**
```bash
ffmpeg -loop 1 -i card_${fn}.png \
    -f lavfi -i anullsrc=r=44100:cl=stereo \
    -c:v libx264 -t 4 -pix_fmt yuv420p -r 25 \
    -c:a aac -shortest \
    card_${fn}.mp4
```
⚠️ Обязательно добавлять аудио (`anullsrc`), иначе concat не объединит аудиопотоки.

**3. Нарезка клипа из исходника**
```bash
ffmpeg -ss $start -i source.mp4 -t $dur \
    -c:v libx264 -crf 18 -preset fast \
    -c:a aac -b:a 128k clip_${fn}.mp4
```

**4. Конкатенация карточки + клип**
```bash
# list.txt:
# file 'card_fn.mp4'
# file 'clip_fn.mp4'
ffmpeg -f concat -safe 0 -i list.txt -c copy ${fn}.mp4
```

**5. Загрузка на сервер**
```bash
scp -i ~/.ssh/aidacamp_prod ${fn}.mp4 root@159.194.223.55:/var/www/aidacamp-media/videos/darya/
```

## Пайплайн генерации VTT (субтитры)

### Критичное правило: тайминг относительно полного видео

Whisper получает чистую речь (без тишины карточки), а потом тайминги сдвигаются на реальный старт речи.

**Шаг 1 — Найти точный старт речи в каждом видео**
```python
import subprocess, struct, math

def find_speech_start(mp4):
    for t_tenth in range(0, 60):
        t = t_tenth / 10.0
        r = subprocess.run(
            ['ffmpeg', '-ss', str(t), '-i', mp4, '-t', '0.1',
             '-vn', '-f', 's16le', '-ac', '1', '-ar', '16000', '-'],
            capture_output=True
        )
        samples = struct.unpack('<' + 'h'*(len(r.stdout)//2), r.stdout)
        rms = math.sqrt(sum(s*s for s in samples)/len(samples))
        if rms > 800:
            return t
    return 4.0
```
Типичные значения: 4.1–5.1s (карточка ≈ 4s, но не ровно).

**Шаг 2 — Извлечь аудио начиная с речи (пропустить тишину карточки)**
```bash
ffmpeg -ss $speech_start -i ${fn}.mp4 \
    -vn -f mp3 -ar 16000 -ac 1 -ab 64k \
    speech_audio.mp3
```

**Шаг 3 — Отправить в Whisper**
```bash
curl -X POST https://api.openai.com/v1/audio/transcriptions \
    -H "Authorization: Bearer $OPENAI_API_KEY" \
    -F model=whisper-1 \
    -F language=ru \
    -F response_format=vtt \
    -F "file=@speech_audio.mp3;type=audio/mpeg"
```
⚠️ Указывать `type=audio/mpeg` явно — без него API может не принять файл.

**Шаг 4 — Сдвинуть тайминги на $speech_start**
```python
import re

def shift_vtt(text, offset):
    def shift(m):
        h, mn, s = int(m.group(1)), int(m.group(2)), float(m.group(3))
        total = max(0.0, h*3600 + mn*60 + s + offset)
        h2 = int(total//3600); total -= h2*3600
        mn2 = int(total//60);  s2 = total - mn2*60
        return f"{h2:02d}:{mn2:02d}:{s2:06.3f}"
    return re.sub(r'(\d{2}):(\d{2}):(\d{2}\.\d{3})', shift, text)

vtt_shifted = shift_vtt(whisper_vtt, speech_start)
```

Итог: первый cue VTT = $speech_start, что точно совпадает с началом речи в видео.

## Karaoke-оверлей (JS в VideoGallery.astro)

- VTT парсится вручную через `fetch()` + регулярки
- `rafLoop()` на каждом кадре проверяет `videoEl.currentTime`
- Слова внутри cue подсвечиваются по равномерному распределению времени: `wordDur = (cue.e - cue.s) / words.length`
- Цвета: прошедшие = `rgba(255,220,0,0.5)`, активное = `#fff`, будущие = `#FFE000`

## Грабли

| Симптом | Причина | Решение |
|---|---|---|
| Субтитры на 1-й секунде | Uniform +4s offset, но карточки длиной не ровно 4s (4.1–5.1s) | Измерять реальный старт речи через RMS, сдвигать индивидуально |
| Нет звука в склеенном видео | Карточка-MP4 без аудиопотока, concat -c copy не может смиксить | Добавлять `anullsrc` при генерации карточки |
| Whisper API ошибка | ffmpeg писал .mp3 по расширению файла, а не через -f mp3 | Всегда указывать `-f mp3` явно |
| Субтитры не обновляются в браузере | Кэш браузера держит старый VTT | Инкрементировать `?v=N` в data-track при замене VTT |
| Burned-in субтитры в исходнике | Видео нарезалось из уже обработанного файла с наложенными субтитрами | Брать только оригинальный исходник без субтитров |
