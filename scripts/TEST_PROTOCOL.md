# Протокол тестирования бота АйДаКемп

**Что тестируем:** AI-чат на странице `/ask` — отвечает на вопросы родителей об IT-лагере.  
**Где:** https://dev.aidacamp.ru/ask (тестовый стенд)  
**Время:** ~20–30 минут на один набор сценариев

---

## Как проходить тест

1. Открой ссылку в браузере (лучше с телефона — так видишь как видит мама)
2. Выбери свой возрастной профиль или просто напиши первый вопрос
3. Задавай вопросы из своего сценария — **своими словами**, не копируй дословно
4. После каждого ответа оцени его по шкале ниже
5. Запиши замечания в форму обратной связи (ссылка в конце)

---

## Шкала оценки каждого ответа

| Оценка | Описание |
|--------|----------|
| **5 — Отлично** | Точно, по делу, как живой человек. Хочется записаться |
| **4 — Хорошо** | Полезно, но чуть суховато или не полностью |
| **3 — Нормально** | Ответил, но что-то не так: слишком общо, не то акцентировал |
| **2 — Плохо** | Ответ не по теме, выдумал факты или говорит как скрипт |
| **1 — Ошибка** | Сказал что-то неверное, странное или агрессивное |

## Что особенно проверяй

- **Не выдумывает ли факты?** (цены, даты, что входит в стоимость)
- **Не говорит ли «ребёнок»?** (должно быть «он», «она», «дети», «участник»)
- **Не пафосный ли тон?** («вернулся другим человеком», «раскрылся» — красный флаг)
- **Не предлагает ли Unity или кибербезопасность?** (этих курсов нет)
- **Трансфер — платный или бесплатный?** Должно быть: *через партнёров, за доп. оплату*
- **Короткие ответы или длинные?** (норма — 2–4 предложения, не простыня)

## Для команды: как запустить автотест

```bash
# Быстрый прогон всех профилей
node scripts/test-bot.mjs

# Конкретный профиль + полные ответы
node scripts/test-bot.mjs --profile тревожная-мама --verbose

# HTML-отчёт для отправки
node scripts/test-bot.mjs --report ./report.html

# На проде
node scripts/test-bot.mjs --prod --report ./report-prod.html
```

Отчёт деплоится на сервер:
```bash
scp report.html root@159.194.223.55:/var/www/aidacamp-dev/current/bot-report/index.html
```

Ссылка: **https://dev.aidacamp.ru/bot-report/**
