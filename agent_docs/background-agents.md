# Фоновые агенты (headless) + Preflight — детально

> Вынесено из корневого `CLAUDE.md` (чистка). Дублирует глобальный `~/.claude/CLAUDE.md`
> и `~/MCP/AGENT_INSTRUCTIONS.md` → раздел 0. Механика вшита в хуки (`.claude/settings.json` → `scripts/hooks/`).

## Запуск

```bash
claude -p "задача" \
  --no-session-persistence \
  --no-chrome \
  --tools "Bash,Read,Write,Edit,Glob,Grep" \
  --max-turns 10 \
  --permission-mode bypassPermissions
```

**НЕ используй `--bare`** — отключает OAuth.

Полная инструкция: `~/MCP/AGENT_INSTRUCTIONS.md` → раздел 0.

## 🛫 Preflight перед конвейером и контракт фоновых задач (аудит 17.07.2026)

Три правила; проза ниже — только про то, что греп поймать не может:

1. **Preflight.** Перед очередью headless-агентов или конвейером с внешним API —
   одна дешёвая проверка токена/биллинга: `bash scripts/preflight.sh claude [host]`
   или `REPLICATE_API_TOKEN=... bash scripts/preflight.sh replicate`. Хук
   `guard-preflight.py` заблокирует очередь `claude -p` и POST в Replicate без
   свежего маркера (30 мин). Для других API (OpenAI, Gemini, …) общего
   греп-паттерна «это старт конвейера» нет — там правило остаётся прозой: тот же
   дешёвый вызов ДО постройки. Инциденты: Replicate «insufficient credit» после
   ~4 ч работы (16.07), 9 агентов вхолостую на протухшем OAuth (15.07).
2. **Файловый контракт.** Фоновый субагент пишет полный результат в файл (путь —
   в брифе), финальным сообщением возвращает только резюме — зеркало правила
   nohup+лог для Bash. Хук `guard-agent-output.py` не выпустит фоновый Agent-запуск
   без пути в prompt. Инцидент: 5 из 9 ревьюеров умерли при рестартах без следа —
   0 Write (16.07).
   **Итоговый файл — в `~/.claude/agent-results/`, НЕ в скретчпад сессии.** Скретчпад
   чистится на ходу и исчезает вместе с сессией, поэтому как адрес результата
   бессмысленен: файл может быть написан и стёрт, а реестр покажет задачу
   незакрытой навсегда. Разбор 01.08.2026: 45 из 46 «незакрытых» в окне сверки были
   именно такими — список превратился в шум, который перестают читать. Промежуточные
   черновики агента в скретчпаде — нормально, правило только про итог.
3. **Реестр фоновых задач.** Каждый фоновый запуск попадает в
   `.claude/agent-tasks.jsonl` (хук `agent-task-registry.py`), при старте/рестарте
   сессии session-start.sh сверяет реестр с диском: файл результата есть и непуст —
   задача закрыта, нет — задача показывается как незакрытая. Статус выводится из
   артефакта, не из обещания. Инцидент: «Перезапущу» написано — перезапуска не было
   (17.07).

Самотесты стражей: `npm run check:hooks` (встроен в `npm run guard`).
