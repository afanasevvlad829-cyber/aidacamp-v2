Как использовать офлайн или на своём сервере

Полная инструкция — открывайте файл без интернета или раздавайте его студентам

1️⃣ Скачать файл локально

В верхнем правом углу превью нажмите кнопку «Скачать» (Download) и сохраните programming-tools-ru.html в любую папку на компьютере, флешке или диске. Файл — один-единственный, никаких дополнительных папок не нужно.

Один файл

2️⃣ Открыть без интернета

Дважды кликните по файлу — он откроется в браузере (Chrome, Firefox, Яндекс, Edge). Работает оффлайн: все стили, поиск, фильтры и переключатель темы встроены прямо в HTML. Единственное, что подгружается из сети — шрифты с Google Fonts. Без интернета сайт будет использовать системный шрифт (выглядит чуть проще, но всё читается).

Любой браузер

3️⃣ Полный офлайн (со шрифтами)

Если нужен 100% офлайн без потери дизайна — откройте файл в текстовом редакторе (VS Code, Notepad++) и удалите 3 строки в <head>:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?..." rel="stylesheet">

После этого файл вообще не требует интернета.

Правка файла

4️⃣ Раздать через локальный сервер (Python)

Если установлен Python — откройте папку с файлом в терминале и выполните:

python -m http.server 8000

Откройте в браузере http://localhost:8000/programming-tools-ru.html. Все в вашей локальной сети могут зайти по адресу http://ВАШ_IP:8000/...

PythonЛокальная сеть

5️⃣ Раздать через Node.js

Если установлен Node.js — выполните в папке с файлом:

npx serve .

Команда сама запустит сервер и покажет адрес для доступа из браузера. Идеально для класса или лагеря.

Node.jsКросс-платформа

6️⃣ Хостинг на внешнем сервере

Загрузите файл на любой хостинг — бесплатно работают:
• GitHub Pages — закиньте файл в репозиторий, включите Pages в Settings
• GitVerse Pages (РФ) — российский аналог
• Netlify Drop — просто перетащите файл в окно
• Свой VPS (nginx/Apache): положите файл в /var/www/html/

БраузерБесплатно

7️⃣ Установить как приложение (PWA-стиль)

В Chrome/Edge: откройте файл → меню (⋮) → «Сохранить страницу как…» → формат «Веб-страница, один файл» (.mhtml). Получится автономный файл-приложение, которое запускается двойным кликом и работает совсем без сети.

Браузер

8️⃣ Распечатать или сохранить в PDF

В браузере нажмите Ctrl+P (Windows) или Cmd+P (Mac) → «Сохранить как PDF». В CSS уже прописаны правила печати — карточки не разрываются между страницами, панель поиска скрывается.

Ctrl + P
💡 Краткий итог: файл полностью самодостаточен. Самый быстрый способ — просто скачать и открыть в браузере (шаги 1–2). Для полного оффлайна — удалите ссылки на Google Fonts (шаг 3). Для класса — раздайте через локальный сервер (шаги 4–5). Для онлайн-доступа всех студентов — выложите на GitHub Pages или GitVerse (шаг 6).
