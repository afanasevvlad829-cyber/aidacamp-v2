Python Test - Kid-Friendly Edition v2
======================================
Открой index.html в любом современном браузере (Chrome, Edge, Firefox, Safari).
Работает офлайн. Полностью адаптивно (телефон/планшет/ПК).

Что внутри (v2):
- 50 вопросов вместо 40
- 3 уровня сложности: Easy (2 XP) / Medium (3 XP) / Hard (4-5 XP)
- 4 типа вопросов: множественный выбор, верно/неверно, заполни пропуск, drag & drop

Темы:
- Основы Python (переменные, типы, операторы, ввод/вывод)
- Циклы (for, while, break)
- Функции (def, return, lambda, аргументы)
- Списки, срезы, методы
- Кортежи и множества
- Строки (срезы, методы, f-строки)
- Словари (доступ, методы, итерация)
- ООП (классы, __init__, self)
- Исключения (try/except/finally)
- Математика (степени, abs, min, math)
- Логические задачи (без кода)
- Сортировка и алгоритмы (бинарный поиск, сложность)
- Рекурсия (факториал)
- Списковые включения
- Отладка (поиск ошибок в коде)

Интерактив:
- Звуки клика, правильного ответа, неправильного, перехода, победы (Web Audio API, без файлов)
- Кнопка включения/выключения звука (вверху справа)
- Анимации pop/wiggle/shake/bounce
- Конфетти на финале
- Большие touch-цели для тач-устройств (до 380px)
