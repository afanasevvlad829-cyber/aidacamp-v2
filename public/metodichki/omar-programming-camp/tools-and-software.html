📘 Пошаговые инструкции по установке

1. Установка VS Code (редактор кода)
  1. Откройте code.visualstudio.com/Download — сайт открывается из РФ.
  2. Скачайте установщик для своей ОС и запустите.
  3. В разделе расширений установите: Russian Language Pack, Python, Live Server, Codeium (AI-автокомплит).
  4. Готово — можно открывать папку проекта через File → Open Folder.
2. Установка Python и pip-зеркала
  1. Скачайте Python 3.12+: python.org/downloads.
  2. При установке поставьте Add Python to PATH.
  3. Проверьте: python --version.
  4. Если pip медленный — настройте зеркало Яндекса: 
    pip config set global.index-url https://mirror.yandex.ru/mirrors/pypi/simple/
3. Установка Node.js и npm-зеркала
  1. Скачайте LTS-версию: nodejs.org/ru.
  2. Проверьте: node -v и npm -v.
  3. Если npm медленный, переключитесь на зеркало: 
    npm config set registry https://registry.npmmirror.com/
4. Установка Java (Liberica JDK от российской BellSoft)
  1. Скачайте: bell-sw.com/pages/downloads.
  2. Проверьте: java -version.
  3. Для IDE используйте IntelliJ IDEA Community — бесплатно.
5. Установка Git и российских Git-хостингов
  1. Git: git-scm.com/downloads.
  2. Создайте аккаунт на GitVerse или GitFlic — работают без VPN.
  3. Базовые команды: 
    git init
git add .
git commit -m "init"
git remote add origin https://gitverse.ru/user/repo.git
git push -u origin main
6. Подключение GigaChat / YandexGPT (бесплатные AI-API)
  1. GigaChat: зарегистрируйтесь на developers.sber.ru, получите Authorization Key.
  2. YandexGPT: создайте аккаунт в Yandex Cloud, активируйте сервис.
  3. Положите ключи в переменные окружения GIGACHAT_API_KEY / YANDEX_API_KEY.
7. Локальные AI-модели (без интернета)
  1. Скачайте Ollama или LM Studio.
  2. Загрузите модель: ollama pull llama3.1 или ollama pull qwen2.5.
  3. Запустите: ollama run qwen2.5 — работает оффлайн.
8. Если что-то не скачивается из России
  • Поменяйте DNS на 77.88.8.8 (Яндекс) или 1.1.1.1 (Cloudflare).
  • Используйте зеркало Яндекса для PyPI, Ubuntu, Debian.
  • Docker-образы — через huecker.io.
  • npm — через npmmirror.com.
