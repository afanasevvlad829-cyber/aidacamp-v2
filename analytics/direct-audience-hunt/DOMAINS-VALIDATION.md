# Валидация доменов — 14 сегментов (этап 2, шаг 1)

> Метод: `curl -sI -L --connect-timeout 5 --max-time 10` (HEAD, следуем редиректам) с сервера Влада (curl/8.7.1, macOS).
> Где HEAD давал 000/зависание — проверено повторно через HTTP-фолбэк, `dig`/`host` (DNS) и в отдельных случаях WebFetch (сверка бизнеса с описанием брифа).
> Дата проверки: 2026-07-24.

Статусы:
- **жив** — сайт отвечает 2xx/3xx на итоговый URL
- **мёртв (NXDOMAIN)** — домен не зарегистрирован / не резолвится
- **мёртв (парковка)** — домен резолвится, но на парковочный IP reg.ru (`31.31.205.163`) — сайта фактически нет
- **не отвечает** — резолвится, есть IP, но HTTP(S)-соединение не устанавливается/зависает (не обязательно мёртв — может быть гео-фильтрация со стороны хостера к IP агента)
