## Шаг 3. Прогноз охвата «Посещают сайты» через API — итог исследования

**Факт (не гипотеза):** в Яндекс.Директ API v5 (актуальная версия) сервиса прогноза охвата/бюджета/CPM **нет**. Официальная документация по миграции на v5 прямо говорит: «В настоящее время получение прогноза бюджета и подбор фраз в API версии 5 не поддерживаются». Метод `CreateNewForecast`, который умел строить прогноз, существовал только в API v4 и Live4 — обе версии в документации помечены как **(deprecated)**.
Источники: `yandex.ru/dev/direct/doc/ref-v5/concepts/methods.html` (список сервисов v5: Campaigns, AdGroups, Ads, Keywords, Bids, vCards, Sitelinks, AdImages, RetargetingLists, AudienceTargets, Reports, Changes, Dictionaries, Clients, AgencyClients — Forecast среди них нет), `yandex.ru/dev/direct/doc/dg-v4/concepts/Versions_v4-docpage` и `Versions_live4-docpage` (обе версии deprecated).

**Вывод:** программного способа снять прогноз охвата/показов для `AudienceTargets` («Посещают сайты») без интерфейса — не существует. Пытаться обойти через `direct_manage_campaign`/`direct_manage_adgroup` не нужно и прямо запрещено по брифу (создаст реальные активные объекты + инструмент уже показал проблемы с вложенной структурой стратегии в этой сессии).

### Инструкция для Влада — как снять прогноз вручную, без траты бюджета

1. Зайти в Яндекс.Директ → **«Мастер кампаний»** → «Создать кампанию».
2. Выбрать цель (трафик на сайт/конверсии — не важно для целей прогноза, черновик не публикуется).
3. В настройках группы объявлений → **«Аудитория» → «Интересы и привычки» → «Посещают сайты»** → вставить список доменов сегмента (до определённого лимита доменов на условие — уточнить лимит в интерфейсе).
4. Указать регион (Москва и МО), возраст/пол если нужно.
5. **Не публиковать черновик.** На этапе настройки группы Директ показывает **прогнозные показы/охват** справа от формы (блок «Прогноз показов» или похожий, точное название зависит от текущей версии интерфейса) — это оценка ДО списания денег и без активации кампании.
6. Записать цифру, закрыть черновик без публикации (или сохранить как черновик и не активировать — деньги не списываются, пока кампания не запущена и не прошла модерацию с активным статусом).
7. Повторить для каждого сегмента отдельно (домены сегмента как одно аудиторное условие).

Это ручная разовая процедура на ~14 сегментов (~5-10 минут на сегмент) — оценочно 1.5-2 часа. Не автоматизируется без нарушения ограничений задачи.

### Косвенная оценка (не то же самое, что прогноз Директа)

Как прокси использована сумма частотности Wordstat по ключам сегмента (шаг 2) — с чёткой оговоркой в `WORDSTAT-DATA.md`, что это частотность точных длинных фраз из брифа, а не оценка реального охвата аудиторного таргетинга по доменам. Открытых бесплатных источников трафика по конкретным доменам (аналог SimilarWeb) в рамках сессии не проверялось — не входило в доступный инструментарий без выхода за периметр `aidacamp-tools` MCP.

## Рекомендация по шорт-листу (критерий: 3-4 сегмента с РАЗНОЙ логикой сигнала, один бюджет/период 2-3 недели, метрика — CPL + качество лида)

Черновик Влада: **A1, A3, H1 (глэмпинги, отдельно), B2**. По итогам валидации это подтверждается:

1. **A1 (игровой компьютер)** — логика: продуктовый мэтч + вина/компенсация. Домены после замены в порядке (hyperpc.ru + 4 живых аналога), invasion-labs.ru убрать как ошибочный. Разная логика от остальных — единственный сегмент с прямым продуктовым мостиком.
2. **A3 (частные школы)** — логика: статусная преемственность образовательной траектории. Домены в отличном состоянии (7-8/9 живы). Разная логика от A1 — не продукт, а статус+образование.
3. **B2 (ЦУМ/люкс, контроль)** — логика: чистые деньги, без сигнала ребёнка вообще. Домены в отличном состоянии (4/5). Разная логика от A1/A3 — это контроль гипотезы «достаточно ли просто денег+возраста».
4. **H1 (глэмпинги)** — уже отдельная активная кампания, не часть этой оценки.

Это даёт 3 действительно разных логики сигнала (продукт / статус-образование / чистые деньги) + существующий трек H1 (стиль жизни/отдых) — четыре разных гипотезы одновременно, как и требовал критерий.

**Явно НЕ добавлять в эту волну:**
- **B6 (wellness/ретриты)** — пересекается с H1 на один бюджет, по прямому указанию брифа. Либо отложить до завершения теста H1, либо слить в общую кампанию «отдых для себя» с глэмпингами.
- **B3 (премиум-фитнес)** — пересекается с B2 по профилю (сам бриф это отмечает), решать после результатов B2.
- **B4 (недвижимость)** — сам бриф маркирует как «3-я волна» из-за длинного цикла сделки, несмотря на самую высокую частотность ключей в этой оценке (1327/мес) — высокая частотность ≠ быстрый предсказуемый CPL.

**Кандидат на вторую волну (не в первой четвёрке, но домены и частотность в хорошем состоянии):** B1 (премиум-авто, Lixiang/Voyah/Zeekr) — сильный сигнал денег, третья по частотности ключей (573/мес) после полной замены доменного списка.
