## ⚠️ Важная методологическая оговорка

Числа ниже — частотность **точной фразы** (`base`, без склонений/перестановок слов и без включения расширений с доп. словами) для длинных гипотетических фраз из брифа, а не для широких коммерческих ключей. Это значит:
- Абсолютные значения **сильно занижены** относительно реального объёма спроса в теме (например «hyperpc цена» = 9/мес выглядит очень низко для известного бренда — это счётчик точной фразы, а не всех формулировок с этим брендом).
- Использовать эти цифры можно **только для относительного сравнения сегментов друг с другом** (у кого фразы из брифа хоть как-то ищут, у кого — почти никогда), а не как абсолютный прогноз объёма трафика.
- Ключи с частотностью 0 не значат «спроса нет» — значит «эту конкретную формулировку никто не вбивает». Реальный спрос в теме может измеряться через более широкие ключи (не входит в объём этой задачи).
