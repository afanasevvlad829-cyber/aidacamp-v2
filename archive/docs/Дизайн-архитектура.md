## 1. Общие понятия и правила

### Главный принцип
Один акцентный цвет — оранжевый. Взгляд управляется **иерархией**, а не украшением. Максимум 2 залитых оранжевых элемента на экране одновременно.

### Система кнопок — 4 уровня

| Уровень | Вид | Использование |
|---------|-----|---------------|
| 1 | Залитый оранжевый `#ec7c00` | «Забронировать место», «Выбрать», «Отправить заявку» |
| 2 | Контурный оранжевый, фон `#fff0e0`, рамка `#ec7c00` | «Перезвоните мне», «Проверить занятость», «Узнать больше» |
| 3 | Нейтральный серый | Табы, фильтры FAQ, меню шапки |
| 4 | Бейджи (не кнопки) | «Популярная», «места есть», роли хакатона |

> **Правило disabled:** всегда `bg-slate-200`. Никогда оранжевый с opacity.

### Цветовая схема

```
Primary:        #ec7c00
Primary light:  #fff0e0
Primary dark:   #b84800
Dark navy:      #0f1c2e
Заголовки:      #0f172a
Текст body:     #1e293b
Текст muted:    #475569
Текст hint:     #94a3b8
Рамки:          #e2e8f0
```

### Типографика

| Элемент | Десктоп | Мобиле |
|---------|---------|--------|
| H1 | 44px / 700 | 36px / 700 |
| H2 | 30px / 700 + оранжевая полоса слева | ← то же |
| H3 | 22px / 700 | ← то же |
| Лид | 16px / 400 `#475569` | ← то же |
| Body | 15px / 400 `#1e293b` | ← то же |
| Small | 13px / 400 `#64748b` | ← то же |
| Caption | 11px / 600 caps `#94a3b8` | ← то же |

### Законы UX

- **Fitts** — кнопки ≥44px на мобиле
- **Hick** — форма 2 поля, модалка 3 варианта
- **Von Restorff** — максимум 2 залитых оранжевых на экране
- **Fogg** — мотивация + возможность + триггер
- **Чалдини** — механика «Согласны» = микро-обязательство
