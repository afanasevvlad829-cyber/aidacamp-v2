# Стандарты кода

Читай, когда меняешь UI, шаблоны или стили. Типографика, цвета, иконки — `DESIGN_SYSTEM.md`; стек и структура — `DEV_PROTOCOL.md`.

## UI-архитектура

1. Структура и поток данных задаются десктопной версией — это единственный источник правды.
2. Мобильная версия — слой представления, не отдельная ветка UI.
3. Не дублируй разметку под mobile/desktop ради фичи. Если правка визуальная — меняй CSS/классы/шаблон, не бизнес-логику и не состояние.
4. Одно состояние и один пайплайн действий на оба вида; различается только рендер.
5. Legacy-режим в прод-правках не используется.
